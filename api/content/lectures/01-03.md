## コマンドラインとは

マウスで操作する GUI に対して、文字でコマンドを入力してコンピューターを操作する方法を **CLI**（コマンドラインインターフェース）といいます。開発では、プログラムのコンパイルや実行、サーバーの操作などで日常的に使います。

Windows では「コマンドプロンプト」（`cmd.exe`）で、MS-DOS 由来のコマンドを使えます。

## よく使うコマンド

| コマンド | 意味 | 例 |
|---|---|---|
| `cd` | 今いるフォルダを移動する | `cd C:\work` / `cd ..`（1 つ上へ） |
| `dir` | フォルダの中身を一覧する | `dir` / `dir *.java` |
| `mkdir` | フォルダを作る | `mkdir sample` |
| `copy` | ファイルをコピーする | `copy a.txt b.txt` |
| `move` | ファイルを移動・名前変更する | `move a.txt backup\` |
| `del` | ファイルを削除する | `del old.txt` |
| `type` | ファイルの中身を表示する | `type readme.txt` |
| `echo` | 文字を表示する | `echo Hello` |
| `cls` | 画面を消す | `cls` |

> `del` で消したファイルは、ごみ箱に入らずに削除されます。ワイルドカード（`*`）と組み合わせるときは特に注意しましょう。

## パス

ファイルの場所を表す文字列を **パス** といいます。

- **絶対パス**: ドライブから書く。`C:\work\sample\Main.java`
- **相対パス**: 今いるフォルダから書く。`sample\Main.java`、`..\other`（`..` は 1 つ上）

## リダイレクトとパイプ

- `>` : 出力をファイルに書く（上書き）。`dir > list.txt`
- `>>` : 出力をファイルに追記する
- `|` : 前のコマンドの出力を、次のコマンドの入力にする。`dir | find ".java"`

## バッチ処理とバッチファイル

決まった手順をまとめて自動で実行することを **バッチ処理** といいます。Windows では、コマンドを並べたテキストを `.bat` ファイルとして保存すると、ダブルクリックやコマンド名で一度に実行できます。

```bat
@echo off
rem Java をコンパイルして実行するバッチ
cd /d %~dp0
javac Main.java
if %ERRORLEVEL% neq 0 (
  echo コンパイルに失敗しました
  exit /b 1
)
java Main
```

- `@echo off`: 実行するコマンド自体を表示しない
- `rem`: コメント
- `%~dp0`: バッチファイルが置かれているフォルダ
- `%ERRORLEVEL%`: 直前のコマンドの終了コード（0 なら成功）

## ポイント

- CLI は「同じ操作を正確に繰り返す」のに向いている
- 手順をバッチにしておくと、手作業のミスが減り、ほかの人にも渡せる
- 終了コードを確認して、失敗したら止まるように書く
