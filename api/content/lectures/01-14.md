## まずはここから

同じことを何度もしたいとき、同じ行をたくさん書く代わりに繰り返しを使います。『こんにちはを3回表示する』から始めましょう。何回で終わるかも、セットで考えます。

### 最初に覚える4つの言葉

#### 繰り返し

同じ処理を何度も実行すること。

**具体例：** 名前を3人分順番に表示する。

#### for文

回数や数の変化を指定する繰り返し。

**具体例：** 0から2まで1ずつ増やす。

#### while文

条件が成り立つ間続ける繰り返し。

**具体例：** 残り件数がある間処理する。

#### 無限ループ

終了せず繰り返し続ける状態。

**具体例：** 終了条件に使う値を更新し忘れる。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## 反復処理とは

条件を満たす間、同じ処理を繰り返す流れです。データを 1 件ずつ処理したり、決まった回数だけ処理したりするときに使います。

フローチャートでは、ひし形で条件を判定し、True なら処理をして **ひし形に戻る** 矢印を描きます。

```text
[i = 1]
   ↓
◇ i <= 5 ? — False → [終了]
   ↓ True
[i を表示]
   ↓
[i = i + 1]
   ↓
 （ひし形に戻る）
```

## for 文（回数が決まっているとき）

```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
// 1 2 3 4 5
```

`for (初期化; 条件; 更新)` の順に書きます。

## while 文（条件で続けるとき）

```java
int total = 0;
int n = 1;
while (total < 100) {
    total += n;
    n++;
}
```

回数があらかじめわからないときは `while` を使います。条件を最初に判定するので、1 回も実行されないこともあります。

## do-while 文（少なくとも 1 回実行するとき）

```java
int input;
do {
    input = readNumber();
} while (input < 0); // 正しい値が入力されるまで繰り返す
```

## 拡張 for 文（配列やリストの全要素）

```java
int[] scores = {80, 65, 92};
for (int s : scores) {
    System.out.println(s);
}
```

## break と continue

- `break`: 繰り返しを途中で終える
- `continue`: その回の残りを飛ばして、次の回へ進む

```java
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue; // 偶数は飛ばす
    if (i > 7) break;         // 7 を超えたら終わり
    System.out.println(i);    // 1 3 5 7
}
```

## 無限ループに注意

条件がいつまでも偽にならないと、処理が終わりません。

```java
int i = 0;
while (i < 10) {
    System.out.println(i);
    // i++ を忘れると、いつまでも i < 10 のまま
}
```

繰り返しを書いたら、「条件に使う変数が、どこで変化するか」を必ず確認します。

## ポイント

- 回数が決まっていれば `for`、条件で続けるなら `while`
- 少なくとも 1 回実行するなら `do-while`
- 条件の変数が変化しないと無限ループになる

## Option：ループ不変条件

反復の途中で常に成り立つ関係をループ不変条件と呼びます。合計処理なら『ここまでに読んだ要素の合計がsumに入っている』と説明できます。初期化・更新・終了の各時点でこの関係を確かめると、不具合を見つけやすくなります。

**やってみよう：** 最大値探索で、変数maxが各反復の開始時に何を表すか書いてみましょう。
