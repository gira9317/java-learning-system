## まずはここから

プログラミング言語は、コンピューターへの指示を書くための言葉です。JavaやPythonは、その種類です。言語ごとに書き方は違いますが、順番・条件・繰り返しという基本の考え方は共通します。

### 最初に覚える4つの言葉

#### プログラミング言語

コンピューターへの指示を書くための言葉。

**具体例：** Javaで処理を書く。

#### ソースコード

人が言語のルールで書いたプログラム。

**具体例：** エディターで処理の文章を書く。

#### 文法

その言語での正しい書き方のルール。

**具体例：** かっこや文末の書き方を守る。

#### 実行

書いた指示を動かすこと。

**具体例：** コードを動かして結果を表示する。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## プログラミング言語とは

人がコンピューターへの指示を書くための言語です。CPU が直接理解できるのは 0 と 1 の **機械語** だけなので、人が読み書きしやすい言語で書き、機械語に変換して実行します。

## 言語の水準

| 水準 | 内容 | 例 |
|---|---|---|
| 機械語 | CPU が直接実行する 0 と 1 | — |
| アセンブリ言語 | 機械語を記号で書いたもの | MOV、ADD |
| 高水準言語 | 人が読みやすい言語 | Java、C、Python、JavaScript |

## 主な言語と特徴

| 言語 | 実行方式 | 型 | 主な用途 |
|---|---|---|---|
| Java | コンパイル → JVM で実行 | 静的 | 業務システム、Web サーバー、Android |
| C | コンパイル（機械語） | 静的 | OS、組み込み、高速な処理 |
| C# | コンパイル → .NET で実行 | 静的 | 業務システム、ゲーム（Unity） |
| Python | インタープリター | 動的 | データ分析、AI、自動化スクリプト |
| JavaScript | インタープリター（JIT） | 動的 | Web ブラウザ、Web サーバー（Node.js） |
| TypeScript | JavaScript に変換 | 静的 | 大規模な Web 開発 |
| SQL | データベースが解釈 | — | データの検索・更新 |

## 静的型付けと動的型付け

- **静的型付け**: 変数の型を、実行前（コンパイル時）に決める。型の間違いを早く見つけられる
- **動的型付け**: 実行しながら型が決まる。短く書けるが、間違いは実行時までわからない

```java
// Java（静的）
int count = 10;
count = "ten"; // コンパイルエラー
```

```python
# Python（動的）
count = 10
count = "ten"  # エラーにならない
```

## プログラミングの考え方（パラダイム）

| パラダイム | 考え方 | 例 |
|---|---|---|
| 手続き型 | 手順を順番に書く | C |
| オブジェクト指向 | データと処理をまとめた「もの」の組み合わせで考える | Java、C# |
| 関数型 | 値を変えずに、関数を組み合わせる | Haskell。Java のラムダ式・Stream API にも取り入れられている |

多くの言語は、複数の考え方を取り入れています。

## 言語の選び方

言語ごとに得意分野があり、「どれが一番良い」ではなく、**目的・既存のシステム・チームの経験** で選びます。1 つの言語をしっかり学ぶと、ほかの言語も同じ考え方（変数、分岐、繰り返し、関数）で学べます。

## ポイント

- CPU が理解するのは機械語だけ。高水準言語は変換して実行する
- 静的型付けは早く間違いに気づける、動的型付けは手軽に書ける
- 言語は目的に合わせて選ぶ

### 問5【応用】
