## まずはここから

同じスマートフォンで写真も撮れ、地図も見られるのは、動かすプログラムが違うからです。そのプログラムなどをソフトウェアと呼びます。機械そのものと、機械への指示を分けて考えましょう。

### 最初に覚える4つの言葉

#### ソフトウェア

コンピューターへ処理を指示するプログラムなど。

**具体例：** 写真アプリを開いて画像を加工する。

#### ハードウェア

手で触れられる機械や部品。

**具体例：** キーボードや画面を使う。

#### OS

アプリが動く土台となり機械を管理するソフト。

**具体例：** Windowsが複数のアプリの動作を管理する。

#### アプリケーション

利用者の目的に合わせて働くソフト。

**具体例：** 表計算ソフトで売上をまとめる。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## ソフトウェアとは

ハードウェアに「何を、どの順番で行うか」を指示するプログラムや、それに付随するデータのことです。同じハードウェアでも、ソフトウェアを変えれば別の仕事ができます。

## ソフトウェアの分類

| 分類 | 役割 | 例 |
|---|---|---|
| オペレーティングシステム（OS） | ハードウェアを管理し、アプリケーションが動く土台を提供する | Windows、macOS、Linux、Android |
| ミドルウェア | OS とアプリケーションの間で、共通の機能を提供する | データベース（PostgreSQL）、Web サーバー（Apache）、アプリケーションサーバー（Tomcat） |
| アプリケーション | 利用者の目的に合わせた処理を行う | ブラウザ、表計算ソフト、業務システム |

## OS の主な仕事

- **プロセス管理**: 複数のプログラムに CPU の時間を割り振り、同時に動いているように見せる
- **メモリ管理**: プログラムごとにメモリを割り当て、互いに壊し合わないようにする
- **ファイル管理**: ディスク上のデータをファイルとフォルダで扱えるようにする
- **入出力管理**: キーボードやディスプレイ、ネットワークなどの装置を共通の方法で使えるようにする
- **ユーザー管理**: 誰が何をしてよいか（権限）を管理する

アプリケーションは、これらを **OS に依頼して** 使います。たとえば Java でファイルを読むときも、実際の読み込みは OS が行っています。

## ライセンス

ソフトウェアには、利用条件（ライセンス）があります。

- **商用ソフトウェア**: 利用料を払って使う
- **フリーソフトウェア**: 無料で使える（改変や再配布の可否は別）
- **オープンソースソフトウェア（OSS）**: ソースコードが公開され、条件の範囲で改変・再配布できる。MIT、Apache License 2.0、GPL などがある

業務で OSS を使うときは、ライセンスの条件（著作権表示が必要か、改変したソースの公開が必要か など）を必ず確認します。

## ポイント

- ソフトウェアは OS・ミドルウェア・アプリケーションの層に分かれる
- アプリケーションは OS の機能を借りて動いている
- OSS も「何をしてもよい」わけではなく、ライセンスに従う

### 問5【応用】

ブラウザとキーボードの組み合わせで正しいのは？

#### 選択肢

- A. ブラウザが入力装置
