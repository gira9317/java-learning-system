## データ記述言語とは

データや文書の **構造** を、決まった書式で表す言語です。プログラミング言語のように処理の手順を書くのではなく、「何がどう並んでいるか」を書きます。システム間のデータ交換、設定ファイル、画面の作成などで使います。

| 形式 | 主な用途 |
|---|---|
| XML | データ交換、設定ファイル（Maven の pom.xml など） |
| HTML | Web ページの構造 |
| CSS | Web ページの見た目 |
| JSON | Web API のデータ交換、設定ファイル |
| PDF | 印刷・配布用の文書 |

## XML

タグでデータを囲み、入れ子で構造を表します。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<members>
  <member id="1">
    <name>山田</name>
    <age>25</age>
  </member>
</members>
```

- 開始タグと終了タグを必ず対にする（**整形式**）
- 属性（`id="1"`）でも情報を持てる
- スキーマ（XSD）で、書いてよい構造を決めて検証できる

## HTML

Web ページの構造（見出し、段落、リンク、表、フォームなど）を表します。

```html
<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8">
    <title>社員一覧</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>社員一覧</h1>
    <p class="note">2026 年度の新人です。</p>
    <a href="detail.html">詳細</a>
  </body>
</html>
```

見た目（色や大きさ）は HTML ではなく CSS で指定し、**構造と見た目を分ける** のが基本です。

## CSS

HTML の要素に、見た目のルールを当てます。

```css
h1 {
  font-size: 24px;
  color: #1d1d1f;
}
.note {
  color: gray;
  margin-top: 8px;
}
```

- **セレクター**（`h1`、`.note`）で対象を選び、**プロパティ: 値** を指定する
- 同じ CSS を複数のページで使い回せる

## JSON

JavaScript のオブジェクトの書き方をもとにした、軽量なデータ形式です。Web API のやりとりで最もよく使われます。

```json
{
  "members": [
    { "id": 1, "name": "山田", "age": 25, "active": true },
    { "id": 2, "name": "佐藤", "age": 23, "active": false }
  ]
}
```

| 型 | 例 |
|---|---|
| 文字列 | `"山田"`（ダブルクォートのみ） |
| 数値 | `25`、`3.14` |
| 真偽値 | `true`、`false` |
| null | `null` |
| 配列 | `[1, 2, 3]` |
| オブジェクト | `{"key": "value"}` |

コメントが書けない、最後の要素のあとにカンマを置けない、といった決まりがあります。Java では Jackson や Gson などのライブラリで、JSON とオブジェクトを相互に変換します。

## XML と JSON の比較

| | XML | JSON |
|---|---|---|
| 読みやすさ | タグが多く冗長 | 簡潔 |
| データ量 | 多い | 少ない |
| 構造の検証 | スキーマ（XSD）が充実 | JSON Schema がある |
| よく使われる場面 | 既存の業務システム、設定、文書 | Web API、新しいシステム |

## PDF

どの環境で開いても **同じ見た目で表示・印刷される** ことを目的にした文書形式です。帳票（請求書、明細など）の出力によく使われます。データの交換用ではなく、人が見るための最終形と考えます。Java では、Apache PDFBox や帳票ツールで作成します。

## ポイント

- XML と JSON はデータの構造を表す。今の Web API は JSON が主流
- HTML は構造、CSS は見た目。分けて書く
- PDF は見た目を固定した配布・印刷用の形式
