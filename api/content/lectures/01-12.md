## 分岐処理とは

条件によって、実行する処理を切り替える流れです。フローチャートでは **ひし形** で表し、ひし形から出る矢印に「True（はい）」「False（いいえ）」を書きます。

```text
       ◇ score >= 60 ?
    True ↙       ↘ False
 [「合格」を表示] [「不合格」を表示]
          ↘     ↙
           [終了]
```

## if 文

```java
if (score >= 60) {
    System.out.println("合格");
} else {
    System.out.println("不合格");
}
```

- 条件式は `true` / `false` になる式
- `else` は省略できる（条件に合わないときは何もしない）

## 3 つ以上に分ける（else if）

```java
if (score >= 80) {
    System.out.println("A");
} else if (score >= 60) {
    System.out.println("B");
} else {
    System.out.println("C");
}
```

条件は **上から順に** 調べられ、最初に当てはまったものだけが実行されます。範囲の広い条件を先に書くと、下の条件に届かなくなるので、順番に注意します。

## switch 文

1 つの値が「どれに等しいか」で分ける場合は、`switch` が読みやすくなります。

```java
switch (day) {
    case "土", "日" -> System.out.println("休日");
    case "月", "火", "水", "木", "金" -> System.out.println("平日");
    default -> System.out.println("不正な曜日");
}
```

（`->` を使う書き方は Java 14 以降。古い書き方の `case ...:` では、各 case の最後に `break;` が必要です。）

## 入れ子（ネスト）

分岐の中に分岐を書けますが、深くなると読みにくくなります。

```java
// 読みにくい
if (user != null) {
    if (user.isActive()) {
        if (user.isAdmin()) {
            showAdminMenu();
        }
    }
}

// 早めに抜ける（ガード節）と読みやすい
if (user == null || !user.isActive()) {
    return;
}
if (user.isAdmin()) {
    showAdminMenu();
}
```

## ポイント

- 分岐はひし形で、出口の矢印に True / False を書く
- `else if` は上から順に判定され、最初に当てはまったものだけ実行される
- 等しいかどうかで分けるなら `switch`
- ネストが深くなったら、条件を整理して早めに抜ける

> **確認しよう**
>
> - 気温が 25 度以上なら「暑い」、10 度未満なら「寒い」、それ以外は「快適」と表示するフローチャートとコードを書いてみましょう。
> - 次の順番の何が問題でしょうか。`if (score >= 60) {B} else if (score >= 80) {A}`
