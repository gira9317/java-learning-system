## まずはここから

プログラムでも、数・文章・はい／いいえを区別します。この種類が『型』です。変数は値に名前を付ける仕組みで、まずは『名前の付いた箱』と考えてかまいません。

### 最初に覚える4つの言葉

#### 変数

値に名前を付けて使う仕組み。

**具体例：** ageという名前で年齢を覚えておく。

#### int

整数を扱うJavaの型。

**具体例：** 人数を3と表す。

#### String

文字列を扱うJavaの型。

**具体例：** 名前を太郎という文字で表す。

#### boolean

trueかfalseを扱うJavaの型。

**具体例：** 合格したかをはい・いいえで表す。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## データ型とは

データの「種類」と、そのデータを表すのに使う **大きさ（ビット数）**、できる **操作** を決めたものです。同じ 0 と 1 の並びでも、整数として読むか、文字として読むかで意味が変わるため、プログラムでは型を決めてデータを扱います。

## 代表的なデータ型

| 種類 | 内容 | 例 |
|---|---|---|
| 整数型 | 小数点のない数 | 0, -15, 2026 |
| 浮動小数点型 | 小数を含む数 | 3.14, -0.5 |
| 文字型 | 1 文字 | 'A', 'あ' |
| 文字列型 | 文字の並び | "Hello" |
| 論理型（真偽値） | 正しいか正しくないか | true, false |

## Java の基本データ型

| 型 | サイズ | 範囲・内容 |
|---|---|---|
| `byte` | 8 ビット | -128 〜 127 |
| `short` | 16 ビット | -32,768 〜 32,767 |
| `int` | 32 ビット | 約 -21 億 〜 約 21 億 |
| `long` | 64 ビット | 約 ±922 京 |
| `float` | 32 ビット | 小数（精度は約 7 桁） |
| `double` | 64 ビット | 小数（精度は約 15 桁） |
| `char` | 16 ビット | 1 文字（UTF-16 の 1 単位） |
| `boolean` | — | `true` / `false` |

文字列は `String` で表します。`String` は基本データ型ではなく、クラス（参照型）です。

## 変数と型

**変数** は、値を入れておく名前付きの箱です。Java では、変数を作る（宣言する）ときに型を決め、その型の値しか入れられません。

```java
int age = 22;
double height = 170.5;
String name = "山田";
boolean passed = true;

age = "二十二"; // コンパイルエラー: int に文字列は入らない
```

型を先に決めておくことで、間違った値を入れるミスを **実行前に** 見つけられます。

## 型の範囲を超えると

整数型は、範囲を超えると反対側の端に回り込みます（**オーバーフロー**）。エラーにはならないので注意が必要です。

```java
int max = Integer.MAX_VALUE; // 2147483647
System.out.println(max + 1); // -2147483648
```

大きな数を扱うときは `long` を使います。

## 浮動小数点の誤差

`double` は 2 進数で小数を表すため、誤差が出ます。

```java
System.out.println(0.1 + 0.2); // 0.30000000000000004
```

金額のように誤差が許されない計算では、`BigDecimal` を使うか、円や銭などの整数で扱います。

## ポイント

- 型は「データの種類・大きさ・できる操作」を決める
- 整数は基本 `int`、大きければ `long`。小数は基本 `double`
- 整数のオーバーフローと、小数の誤差に注意する

## Option：型は業務上の制約も表す

同じ整数でも、年齢・金額・IDは許される操作が違います。型の範囲を選ぶだけでなく、単位や負数の可否も設計に含めます。正確な十進小数にはBigDecimalを検討し、文字列から生成すると意図した十進値を表しやすくなります。

**やってみよう：** 税込金額を計算する際、税率・端数処理・通貨単位をどこで決めるか整理してみましょう。
