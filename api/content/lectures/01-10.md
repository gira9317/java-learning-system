## まずはここから

0と1を並べたデータを、1桁ずつ扱うのがビット演算です。まずは『オン・オフのスイッチが並んでいる』と考えましょう。細かい数の表し方は後から確認すれば大丈夫です。

### 最初に覚える4つの言葉

#### ビット

0か1の1桁。

**具体例：** スイッチのオフとオンを表す。

#### ビットAND（&）

両方が1の桁だけを1にする演算。

**具体例：** 1と0の組では0にする。

#### ビットOR（|）

少なくとも片方が1の桁を1にする演算。

**具体例：** 1と0の組では1にする。

#### フラグ

状態をオン・オフで表す目印。

**具体例：** 読み取り許可があるかを表す。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## ビット演算とは

整数を 2 進数のビットの並びとして扱い、**1 ビットずつ** 演算する方法です。フラグの管理、権限の組み合わせ、通信データの加工、高速な計算などで使います。

| 演算 | Java | 内容 |
|---|---|---|
| AND | `&` | 両方 1 なら 1 |
| OR | `\|` | どちらか 1 なら 1 |
| XOR（排他的論理和） | `^` | 違えば 1、同じなら 0 |
| NOT（反転） | `~` | 0 と 1 を反転 |
| 左シフト | `<<` | 左にずらす（右は 0 で埋める） |
| 右シフト（算術） | `>>` | 右にずらす（左は符号ビットで埋める） |
| 右シフト（論理） | `>>>` | 右にずらす（左は 0 で埋める） |

## 計算の例

```text
      1100 (12)
  &   1010 (10)
  =   1000 (8)

      1100 (12)
  |   1010 (10)
  =   1110 (14)

      1100 (12)
  ^   1010 (10)
  =   0110 (6)
```

## シフト演算と 2 のべき乗

左に 1 ビットずらすと 2 倍、右に 1 ビットずらすと 2 で割った値（切り捨て）になります。

```java
System.out.println(5 << 1);  // 10
System.out.println(5 << 3);  // 40（5 × 2³）
System.out.println(40 >> 2); // 10（40 ÷ 2²）
```

## フラグの管理

1 つの整数の各ビットを、それぞれ ON / OFF のスイッチとして使えます。

```java
final int READ    = 0b001; // 1
final int WRITE   = 0b010; // 2
final int EXECUTE = 0b100; // 4

int perm = READ | WRITE;              // 読み書き可（011）

boolean canWrite = (perm & WRITE) != 0; // ビットが立っているか → true
perm = perm | EXECUTE;                  // 実行権限を追加 → 111
perm = perm & ~WRITE;                   // 書き込み権限を外す → 101
```

Linux のファイル権限（`chmod 755` の 7 = 読み 4 + 書き 2 + 実行 1）も、この考え方です。

## マスク

必要なビットだけを取り出す値を **マスク** といいます。

```java
int color = 0xFF8800;           // RGB
int red   = (color >> 16) & 0xFF; // 0xFF = 255
int green = (color >> 8)  & 0xFF; // 0x88 = 136
int blue  =  color        & 0xFF; // 0x00 = 0
```

## XOR の性質

同じ値で 2 回 XOR すると元に戻ります（`a ^ k ^ k == a`）。簡単な暗号化やチェックサム、データの比較に使われます。

## 論理演算との違い

- `&&` `||` は **真偽値** を扱い、短絡評価をする
- `&` `|` は **整数のビット** を扱う（boolean に使うと短絡評価をしない）

## ポイント

- ビット演算は 1 ビットずつの AND / OR / XOR / NOT
- `<<` は 2 倍、`>>` は 2 で割る
- 「ビットを立てる」は `|`、「調べる」は `&`、「消す」は `& ~`

## Option：ビット集合と意味のある名前

ビットマスクは複数の状態をコンパクトに扱えますが、数値だけでは意味が伝わりません。定数名や、Javaなら用途に応じてEnumSetを使うと読みやすくなります。

**やってみよう：** READ=1、WRITE=2、EXECUTE=4で、複数権限の追加・削除・全件一致を試してみましょう。
