## まずはここから

普段の数は0から9の10種類の数字を使います。コンピューターでは0と1の2種類で表す方法も使います。違う書き方でも、表している数そのものは同じです。

### 最初に覚える4つの言葉

#### 10進数

0〜9の数字で数を表す方法。

**具体例：** 普段の買い物で12円と数える。

#### 2進数

0と1の数字で数を表す方法。

**具体例：** 2を10、3を11と書く。

#### 16進数

0〜9とA〜Fで数を表す方法。

**具体例：** 10をA、15をFと書く。

#### 基数変換

数の表し方を別の進数へ変えること。

**具体例：** 10進数の3を2進数の11へ書き換える。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## 基数とは

数を表すときに、1 桁で使える数字の種類の数を **基数** といいます。普段使う 10 進数は 0〜9 の 10 種類、コンピューターの内部で使う 2 進数は 0 と 1 の 2 種類です。

| 進数 | 使う数字 | 主な用途 |
|---|---|---|
| 2 進数 | 0, 1 | コンピューター内部のデータ |
| 8 進数 | 0〜7 | Linux のファイル権限（`chmod 755`） |
| 10 進数 | 0〜9 | 人間が普段使う数 |
| 16 進数 | 0〜9, A〜F | メモリのアドレス、色（`#FF8800`）、文字コード |

16 進数では、10〜15 を A〜F で表します。

## 位取りの考え方

どの進数も、桁が 1 つ上がるごとに「基数倍」になります。

- 10 進数の 352 = 3×10² + 5×10¹ + 2×10⁰
- 2 進数の 1011 = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8 + 0 + 2 + 1 = **11**

## n 進数 → 10 進数

各桁の数字に「基数のべき乗」をかけて足します。

- 16 進数の 2F = 2×16 + 15 = **47**
- 8 進数の 17 = 1×8 + 7 = **15**

## 10 進数 → n 進数

基数で割り続け、余りを **下から順に** 並べます。

```text
13 を 2 進数にする
13 ÷ 2 = 6 余り 1
 6 ÷ 2 = 3 余り 0
 3 ÷ 2 = 1 余り 1
 1 ÷ 2 = 0 余り 1
→ 下から読んで 1101
```

## 2 進数と 16 進数の相互変換

2 進数の 4 桁は、16 進数の 1 桁にちょうど対応します（2⁴ = 16）。

```text
2 進数   1010 1111
16 進数    A    F   → 0xAF
```

このため、長い 2 進数は 16 進数で書くと読みやすくなります。

## 小数の変換

10 進数の小数を 2 進数にするときは、小数部分に 2 をかけ、整数部分を **上から順に** 並べます。

```text
0.625 を 2 進数にする
0.625 × 2 = 1.25 → 1
0.25  × 2 = 0.5  → 0
0.5   × 2 = 1.0  → 1
→ 0.101
```

0.1 のように、2 進数では割り切れず **無限に続く** 小数もあります。これがコンピューターで小数の計算に誤差が出る原因です。

## Java での書き方

```java
int bin = 0b1101;   // 2 進数（13）
int oct = 017;      // 8 進数（15）
int hex = 0x2F;     // 16 進数（47）

System.out.println(Integer.toBinaryString(13)); // 1101
System.out.println(Integer.toHexString(47));    // 2f
System.out.println(Integer.parseInt("1101", 2)); // 13
```

## ポイント

- 桁の重みは「基数のべき乗」
- 10 進数 → n 進数は「割って余りを下から」、小数は「かけて整数部を上から」
- 2 進数 4 桁 = 16 進数 1 桁
- 0.1 は 2 進数で正確に表せない

### 問5【応用】

#### 選択肢

- A. 10

- D. 0

正解: C

## Option：有限小数になる条件

既約分数の分母が基数の素因数だけで構成されると、その基数で有限小数になります。1/10の分母には5が含まれるため、2進数では有限小数になりません。

**やってみよう：** 1/2、1/5、1/8を2進数と10進数で比べ、有限になる組み合わせを説明してみましょう。
