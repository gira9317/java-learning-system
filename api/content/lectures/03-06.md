## MIME とは

**Multipurpose Internet Mail Extensions** の略です。もともとのメールは英数字のテキストしか送れなかったため、**日本語・画像・添付ファイル** などを送れるように拡張した決まりです。今では、メールだけでなく HTTP でもデータの種類を表すのに使われています。

## メディアタイプ（MIME タイプ）

データの種類を「**タイプ/サブタイプ**」で表します。HTTP の `Content-Type` ヘッダーでも使います。

| メディアタイプ | 内容 |
|---|---|
| `text/plain` | テキスト |
| `text/html` | HTML |
| `text/csv` | CSV |
| `application/json` | JSON |
| `application/pdf` | PDF |
| `application/zip` | ZIP |
| `application/octet-stream` | 種類のわからないバイナリ |
| `image/png`、`image/jpeg` | 画像 |
| `multipart/form-data` | フォームの入力とファイルをまとめたもの |
| `multipart/mixed` | 本文と添付ファイルをまとめたメール |

文字の場合は、文字コードも指定します。`text/plain; charset=UTF-8`

## マルチパート

1 つのメッセージの中に、**種類の違う複数のデータ（パート）** を入れる形式です。各パートは、**境界文字列（boundary）** で区切ります。

### メールの例（本文 + 添付ファイル）

```text
Content-Type: multipart/mixed; boundary="XYZ123"

--XYZ123
Content-Type: text/plain; charset=UTF-8
Content-Transfer-Encoding: base64

（本文を Base64 にしたもの）
--XYZ123
Content-Type: application/pdf; name="report.pdf"
Content-Disposition: attachment; filename="report.pdf"
Content-Transfer-Encoding: base64

（PDF を Base64 にしたもの）
--XYZ123--
```

- `--境界` でパートが始まり、`--境界--` で全体が終わる
- 添付ファイルのようなバイナリは、**Base64** でテキストにして入れる（そのため、メールのサイズは元のファイルの約 4/3 倍になる）
- 件名の日本語も、`=?UTF-8?B?...?=` のようにエンコードして入れる

## HTML メールとテキストメール

`multipart/alternative` を使うと、同じ内容の **テキスト版と HTML 版** を 1 通に入れられます。受け取ったメールソフトが、表示できる方を選びます。

## HTTP でのファイルアップロード

フォームからファイルを送るときは、`multipart/form-data` を使います。

```html
<form action="/upload" method="post" enctype="multipart/form-data">
  <input name="title">
  <input type="file" name="file">
  <button>送信</button>
</form>
```

```http
POST /upload HTTP/1.1
Content-Type: multipart/form-data; boundary=----ABC

------ABC
Content-Disposition: form-data; name="title"

月次報告
------ABC
Content-Disposition: form-data; name="file"; filename="report.pdf"
Content-Type: application/pdf

（PDF のバイナリ）
------ABC--
```

サーブレットでは、`@MultipartConfig` を付けて `req.getPart("file")` で受け取ります。

## ファイルを受け取るときの注意

- **サイズの上限** を設ける（大きなファイルでサーバーを止められないように）
- **種類を確認** する（拡張子や `Content-Type` は偽装できるため、中身でも確かめる）
- 保存するファイル名は、送られた名前をそのまま使わず、サーバー側で決める（`../` などで別の場所に書き込まれるのを防ぐ）

## ポイント

- MIME はデータの種類を表す決まり。`Content-Type` で使う
- マルチパートは、境界文字列で区切って複数のデータをまとめる
- 添付ファイルは Base64、ファイルのアップロードは `multipart/form-data`
- 受け取るファイルは、サイズ・種類・名前を確認する

> **確認しよう**
>
> - 3 MB の PDF をメールに添付すると、メールのサイズはおよそどれくらいになるでしょうか。
> - アップロードされたファイル名をそのまま使って保存すると、どんな危険があるでしょうか。
