## まずはここから

Webページで、ボタンを押すと表示が変わる仕組みにJavaScriptが使われます。名前は似ていますが、Javaとは別の言語です。文字を表示する、クリックに反応する、といった動きをイメージしましょう。

### 最初に覚える4つの言葉

#### JavaScript

Web等で使うプログラミング言語。

**具体例：** ボタンを押すと説明を表示する。

#### DOM

ページの要素をプログラムで扱うための仕組み。

**具体例：** 見出しの文字を変更する。

#### イベント

クリック等の出来事。

**具体例：** ボタンが押されたことを受け取る。

#### 非同期処理

待ちのある処理の完了を後で扱う仕組み。

**具体例：** 通信の返答を待って表示する。

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## JavaScript とは

Web ブラウザの上で動く言語として生まれ、今では Web 画面（フロントエンド）のほぼすべてで使われています。Node.js を使えば、サーバー側でも動かせます。名前は似ていますが、**Java とは別の言語** です。

| 特徴 | 内容 |
|---|---|
| ブラウザで動く | HTML の要素を書き換え、画面に動きを付ける |
| 動的型付け | 変数の型を宣言しない |
| 非同期処理 | 通信の待ち時間に画面を止めない仕組みがある |
| TypeScript | JavaScript に型を付けた言語。大規模な開発で使われる |

## 基本の書き方

```javascript
// 変数: 再代入しないものは const、するものは let（var は使わない）
const name = "山田";
let count = 0;

// 分岐と繰り返し（Java とほぼ同じ）
if (count === 0) {
  console.log("ゼロ");
}
for (let i = 0; i < 3; i++) {
  count += i;
}

// 関数（アロー関数）
const add = (a, b) => a + b;
console.log(add(3, 4)); // 7

// テンプレート文字列
console.log(`${name} さんは ${count} 点`);
```

## == と ===

`==` は型を変換してから比べるため、意外な結果になります。**常に `===`（型も含めて比べる）を使います**。

```javascript
console.log(0 == "0");   // true
console.log(0 === "0");  // false
console.log(null == undefined);  // true
```

## 配列とオブジェクト

```javascript
const scores = [80, 55, 92];
const passed = scores.filter((s) => s >= 60);   // [80, 92]
const doubled = scores.map((s) => s * 2);        // [160, 110, 184]
const total = scores.reduce((sum, s) => sum + s, 0);

const member = { name: "山田", age: 25 };
console.log(member.name);
```

`filter` や `map` は、Java の Stream API と同じ考え方です。

## 画面を操作する（DOM）

```html
<button id="btn">押す</button>
<p id="msg"></p>
<script>
  document.getElementById("btn").addEventListener("click", () => {
    document.getElementById("msg").textContent = "押されました";
  });
</script>
```

利用者が入力した文字を画面に出すときは、`innerHTML` ではなく `textContent` を使います。`innerHTML` に入れると、入力されたタグやスクリプトが動いてしまう危険があります（第 5 章「JavaScript インジェクション」）。

## 非同期処理

サーバーとの通信など、時間のかかる処理は結果を待たずに次へ進み、終わったら続きを実行します。`async` / `await` で、順番どおりに読める形で書けます。

```javascript
async function loadMembers() {
  try {
    const res = await fetch("/api/members");
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    const members = await res.json();
    console.log(members);
  } catch (e) {
    console.error("取得に失敗しました", e);
  }
}
```

## ポイント

- 変数は `const` を基本に、必要なときだけ `let`
- 比較は `===`
- 配列の `filter` / `map` / `reduce` は Stream API と同じ考え方
- 入力値を画面に出すときは `textContent`
- 通信は `async` / `await` で書く

## Option：awaitしてもUIの競合は残る

検索語Aの通信後にBの通信を始めても、Aの応答が遅れて最後に届くことがあります。古い応答を表示しないため、リクエストの識別やAbortController等を検討します。
