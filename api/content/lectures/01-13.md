## まずはここから

『かつ』と『または』を使うと、条件を組み合わせられます。『赤くて丸い』なら両方必要、『赤いか丸い』なら片方でもよい、という違いです。最初は日本語で意味を確かめましょう。

### 最初に覚える4つの言葉

#### AND（かつ）

2つの条件を両方満たすこと。

**具体例：** 会員かつ大人だけを対象にする。

#### OR（または）

少なくとも片方の条件を満たすこと。

**具体例：** 学生または会員なら割引する。

#### 範囲内の条件

下限と上限の両方を満たす条件。

**具体例：** 1以上かつ10以下を選ぶ。

#### かっこ

組み合わせるまとまりを明確にする記号。

**具体例：** 先にまとめたい条件を囲む。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## 複数の条件を組み合わせる

分岐の条件が 1 つで済まないときは、AND（かつ）・OR（または）で組み合わせます。

| 言い方 | 意味 | Java |
|---|---|---|
| A かつ B | 両方を満たす | `A && B` |
| A または B | 少なくとも一方を満たす | `A \|\| B` |
| A ではない | A を満たさない | `!A` |

## ベン図で考える

- **A かつ B**: 2 つの円が重なっている部分
- **A または B**: 2 つの円のどちらかに入っている部分全体

「20 代の会員」は「20 代」と「会員」の重なり、「学生 または 65 歳以上（割引対象）」は 2 つの円の全体です。

## フローチャートでの表し方

AND は、ひし形を **縦に続けて** 並べます。どちらかで False なら外へ出ます。

```text
◇ 年齢 >= 20 ?  — False →┐
  ↓ True                  │
◇ 会員 ?        — False →┤
  ↓ True                  │
[割引する]                 │
  ↓                        ↓
            [終了]
```

OR は、どちらかで True なら同じ処理へ進みます。

```text
◇ 学生 ?        — True  →┐
  ↓ False                 │
◇ 年齢 >= 65 ?  — True  →┤
  ↓ False                 ↓
[通常料金]            [割引料金]
```

## コードで書くと

```java
if (age >= 20 && member) {
    discount();
}

if (student || age >= 65) {
    price = discountPrice;
} else {
    price = normalPrice;
}
```

## よくある間違い

- **範囲の書き方**: `10 <= x <= 20` とは書けない。`10 <= x && x <= 20`
- **「または」の取り違え**: 日本語の「土日または祝日」は OR だが、「18 歳以上で学生ではない」は AND
- **AND と OR を混ぜるとき**: `&&` が `||` より先に評価される。意図を明確にするため括弧を付ける

```java
// 「会員 かつ（土曜 または 日曜）」
if (member && (day.equals("土") || day.equals("日"))) { ... }
```

## ポイント

- 「かつ」は AND、「または」は OR。日本語の言い回しに惑わされない
- フローチャートでは AND はひし形を直列に、OR は True の出口をまとめる
- AND と OR を混ぜるときは括弧を付ける

## 確認しよう

### 問1

「2つの条件を両方満たすこと」に当てはまるものはどれですか。

#### 選択肢

- A. OR（または）
- B. 範囲内の条件
- C. かっこ
- D. AND（かつ）

#### 解答・解説

正解: D

**AND（かつ）**：2つの条件を両方満たすこと。

例：会員かつ大人だけを対象にする。

### 問2

「OR（または）」の説明はどれですか。

#### 選択肢

- A. 少なくとも片方の条件を満たすこと
- B. 組み合わせるまとまりを明確にする記号
- C. 2つの条件を両方満たすこと
- D. 下限と上限の両方を満たす条件

#### 解答・解説

正解: A

**OR（または）**：少なくとも片方の条件を満たすこと。

例：学生または会員なら割引する。

### 問3

「1以上かつ10以下を選ぶ」という例に当てはまるものはどれですか。

#### 選択肢

- A. かっこ
- B. 範囲内の条件
- C. OR（または）
- D. AND（かつ）

#### 解答・解説

正解: B

**範囲内の条件**：下限と上限の両方を満たす条件。

例：1以上かつ10以下を選ぶ。

### 問4

「かっこ」の説明はどれですか。

#### 選択肢

- A. 2つの条件を両方満たすこと
- B. 組み合わせるまとまりを明確にする記号
- C. 少なくとも片方の条件を満たすこと
- D. 下限と上限の両方を満たす条件

#### 解答・解説

正解: B

**かっこ**：組み合わせるまとまりを明確にする記号。

例：先にまとめたい条件を囲む。

### 問5【応用】

『会員または学生』で、会員ではない学生は対象？

#### 選択肢

- A. 必ず会員登録が必要
- B. 対象になる
- C. 対象にならない
- D. 両方満たした人だけ対象

#### 解答・解説

正解: B

ORは少なくとも片方を満たせばよいので、学生なら対象です。

## Option：条件を名前にする

長い条件式は、意味のあるboolean変数や判定メソッドへ分けられます。inBusinessHours、isEligibleのような名前なら、式の意図を追いやすくなります。ただし判定時刻やデータが変わる場合は、いつ評価した値かにも注意します。

**やってみよう：** 営業日と営業時間の条件を別メソッドにし、境界時刻のテストを考えてみましょう。
