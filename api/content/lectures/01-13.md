## 複数の条件を組み合わせる

分岐の条件が 1 つで済まないときは、AND（かつ）・OR（または）で組み合わせます。

| 言い方 | 意味 | Java |
|---|---|---|
| A かつ B | 両方を満たす | `A && B` |
| A または B | 少なくとも一方を満たす | `A \|\| B` |
| A ではない | A を満たさない | `!A` |

## ベン図で考える

- **A かつ B**: 2 つの円が重なっている部分
- **A または B**: 2 つの円のどちらかに入っている部分全体

「20 代の会員」は「20 代」と「会員」の重なり、「学生 または 65 歳以上（割引対象）」は 2 つの円の全体です。

## フローチャートでの表し方

AND は、ひし形を **縦に続けて** 並べます。どちらかで False なら外へ出ます。

```text
◇ 年齢 >= 20 ?  — False →┐
  ↓ True                  │
◇ 会員 ?        — False →┤
  ↓ True                  │
[割引する]                 │
  ↓                        ↓
            [終了]
```

OR は、どちらかで True なら同じ処理へ進みます。

```text
◇ 学生 ?        — True  →┐
  ↓ False                 │
◇ 年齢 >= 65 ?  — True  →┤
  ↓ False                 ↓
[通常料金]            [割引料金]
```

## コードで書くと

```java
if (age >= 20 && member) {
    discount();
}

if (student || age >= 65) {
    price = discountPrice;
} else {
    price = normalPrice;
}
```

## よくある間違い

- **範囲の書き方**: `10 <= x <= 20` とは書けない。`10 <= x && x <= 20`
- **「または」の取り違え**: 日本語の「土日または祝日」は OR だが、「18 歳以上で学生ではない」は AND
- **AND と OR を混ぜるとき**: `&&` が `||` より先に評価される。意図を明確にするため括弧を付ける

```java
// 「会員 かつ（土曜 または 日曜）」
if (member && (day.equals("土") || day.equals("日"))) { ... }
```

## ポイント

- 「かつ」は AND、「または」は OR。日本語の言い回しに惑わされない
- フローチャートでは AND はひし形を直列に、OR は True の出口をまとめる
- AND と OR を混ぜるときは括弧を付ける

> **確認しよう**
>
> - 「平日の 9 時〜17 時、または 土曜の 9 時〜12 時は営業中」を条件式にしてみましょう。
> - 同じ条件をフローチャートで描いてみましょう。
