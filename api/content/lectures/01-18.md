## I/O とストリーム

**I/O**（Input / Output）は、プログラムの外とのデータのやりとりです。ファイル、キーボード、画面、ネットワークなどがあります。

Java では、データを **流れ（ストリーム）** として、先頭から順に読み書きします。読み込みと書き込み、扱う単位によってクラスが分かれています。

| 単位 | 読み込み | 書き込み | 用途 |
|---|---|---|---|
| バイト | `InputStream` | `OutputStream` | 画像、ZIP などのバイナリ |
| 文字 | `Reader` | `Writer` | テキスト |

テキストを扱うときは、**文字コード**（UTF-8 など）を指定して、バイトと文字を変換します。

## テキストファイルを読む

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;

Path path = Path.of("members.csv");
try (BufferedReader reader = Files.newBufferedReader(path, StandardCharsets.UTF_8)) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
} catch (IOException e) {
    System.err.println("読み込みに失敗しました: " + e.getMessage());
}
```

小さなファイルなら、まとめて読むこともできます。

```java
List<String> lines = Files.readAllLines(path, StandardCharsets.UTF_8);
String text = Files.readString(path); // 既定は UTF-8
```

## テキストファイルに書く

```java
try (BufferedWriter writer = Files.newBufferedWriter(Path.of("out.txt"), StandardCharsets.UTF_8)) {
    writer.write("1行目");
    writer.newLine();
}
```

## try-with-resources

ファイルは使い終わったら **必ず閉じる** 必要があります。閉じないと、ファイルがロックされたり、書いた内容が保存されなかったりします。

`try ( ... )` の括弧の中で開いたものは、処理が終わると（例外が起きても）自動で閉じられます。

## バッファ

1 文字ずつディスクに読み書きすると非常に遅くなります。`BufferedReader` / `BufferedWriter` は、ある程度まとめて読み書きして速くします。

## 標準入出力

| ストリーム | Java | 既定のつながり先 |
|---|---|---|
| 標準入力 | `System.in` | キーボード |
| 標準出力 | `System.out` | 画面 |
| 標準エラー出力 | `System.err` | 画面 |

コマンドラインでは、`java Main < input.txt > output.txt` のようにリダイレクトで、つながり先をファイルに変えられます。

## ポイント

- バイナリはバイトストリーム、テキストは文字ストリーム
- テキストは文字コードを明示する
- ファイルは try-with-resources で確実に閉じる
- I/O は失敗しうる（ファイルがない、権限がない）。`IOException` を処理する

> **確認しよう**
>
> - ファイルを閉じ忘れると、どんな問題が起きるでしょうか。
> - CSV ファイルを 1 行ずつ読み、行数を数えるプログラムを書いてみましょう。
