## まずはここから

環境構築は、プログラムを作ったり動かしたりする道具を準備することです。料理の前に道具と材料をそろえる場面に似ています。まずは何を入れ、どの道具を使っているかを確認しましょう。

### 最初に覚える4つの言葉

#### JDK

Javaの開発に必要な道具一式。

**具体例：** Javaのコンパイラー等を用意する。

#### エディター

コードなどの文章を書く道具。

**具体例：** Main.javaへ文字を入力する。

#### PATH

コマンドの実行ファイルを探す場所の設定。

**具体例：** javaという名前の実行ファイルを探す。

#### バージョン

道具やソフトの版を表す情報。

**具体例：** 同じJavaでも使っている版を確認する。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## 環境構築とは

プログラムを書き、動かすために必要なソフトウェアを用意して、設定することです。チームでは「全員が同じ環境で動く」ことが重要なため、手順を残しておきます。

## Java の開発に必要なもの

| もの | 役割 | 例 |
|---|---|---|
| JDK | コンパイラー（`javac`）と実行環境（`java`）のセット | Eclipse Temurin、Oracle JDK |
| エディタ・IDE | コードを書き、実行・デバッグする | IntelliJ IDEA、Eclipse、VS Code |
| ビルドツール | ライブラリの取得、コンパイル、テスト、パッケージ化を自動化する | Maven、Gradle |
| バージョン管理 | 変更の履歴を残し、共有する | Git |

JDK は、長期サポート（**LTS**）のバージョン（17、21、25 など）を選ぶのが一般的です。

## JDK のインストールと確認

インストール後、コマンドプロンプトで次を実行し、バージョンが表示されれば成功です。

```bat
java -version
javac -version
```

表示されない場合は、**環境変数** を確認します。

## 環境変数

OS が持っている設定値で、プログラムから参照できます。

| 変数 | 内容 |
|---|---|
| `JAVA_HOME` | JDK をインストールしたフォルダ。ビルドツールなどが参照する |
| `PATH` | コマンドを探すフォルダの一覧。`%JAVA_HOME%\bin` を追加すると、どこからでも `java` が使える |

```bat
echo %JAVA_HOME%
echo %PATH%
```

## はじめてのプログラム

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

```bat
rem コンパイル（Main.class ができる）
javac Main.java
rem 実行（.class は付けない）
java Main
```

Java 11 以降は、1 ファイルなら `java Main.java` で直接実行もできます。

## つまずきやすい点

| 症状 | よくある原因 |
|---|---|
| 「'java' は、内部コマンドまたは外部コマンド…として認識されていません」 | `PATH` に JDK の `bin` がない |
| 「メイン・クラスMainを検出およびロードできませんでした」 | 実行するフォルダが違う、クラス名の大文字小文字が違う |
| 「クラスMainはpublicであり、ファイルMain.javaで宣言する必要があります」 | ファイル名とクラス名が一致していない |
| コンパイルしたのに古い動きをする | 修正後に再コンパイルしていない |
| 意図しないバージョンの Java が動く | 複数の Java が入っていて、`PATH` の順番が違う。`where java` で確認する |

## ポイント

- JDK を入れ、`JAVA_HOME` と `PATH` を設定する
- `java -version` で確認する
- 手順は文書に残し、チームで同じ環境をそろえる

### 問5【応用】

## Option：環境の版を記録する

トラブル報告には、OS・JDK・ビルドツールの版、実行場所、実行コマンドを添えると再現しやすくなります。環境変数を貼る場合は認証情報を含めないようにします。

**やってみよう：** java -versionとjavac -version、実行ファイルの場所を確認し、同じJDKを指しているか比べてみましょう。
