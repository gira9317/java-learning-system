## まずはここから

『60点以上なら合格』のように、値を比べて判断するのが比較です。結果は『そうである／そうではない』の2つです。記号を全部暗記する前に、以上・未満の境目を確認しましょう。

### 最初に覚える4つの言葉

#### ==

等しいかを調べる比較。

**具体例：** 人数が3と等しいか調べる。

#### >=

以上かを調べる比較。

**具体例：** 点数が60以上か調べる。

#### <

より小さいかを調べる比較。

**具体例：** 年齢が18未満か調べる。

#### 比較結果

条件がtrueかfalseかという結果。

**具体例：** 60>=60の結果をtrueとして使う。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## 比較式とは

2 つの値を比べて、結果を **真（true）か偽（false）** で返す式です。条件分岐や繰り返しの条件に使います。

| 演算子 | 意味 | 例（a = 5, b = 3） | 結果 |
|---|---|---|---|
| `==` | 等しい | `a == b` | false |
| `!=` | 等しくない | `a != b` | true |
| `>` | より大きい | `a > b` | true |
| `>=` | 以上 | `a >= 5` | true |
| `<` | より小さい | `a < b` | false |
| `<=` | 以下 | `b <= 3` | true |

「以上・以下」は等しい場合を **含み**、「より大きい・より小さい（未満）」は **含みません**。

## 境界値に注意

「60 点以上なら合格」を書くとき、`>` と `>=` の取り違えはよくあるミスです。

```java
if (score >= 60) { // 60 点ちょうども合格
    System.out.println("合格");
}
```

テストでは、境界の値（59, 60）を必ず確かめます。

## = と == の違い

- `=` は **代入**（右の値を左の変数に入れる）
- `==` は **比較**（等しいかどうか）

```java
int x = 10;          // 代入
boolean same = x == 10; // 比較 → true
```

## 文字列の比較は equals

Java で文字列（`String`）の中身を比べるときは、`==` ではなく `equals` を使います。`==` は「同じオブジェクトかどうか」を比べるため、中身が同じでも `false` になることがあります。

```java
String a = "java";
String b = new String("java");

System.out.println(a == b);       // false（別のオブジェクト）
System.out.println(a.equals(b));  // true（中身が同じ）
```

## 小数の比較

`double` は誤差を含むため、`==` で比べると思わぬ結果になります。

```java
double d = 0.1 + 0.2;
System.out.println(d == 0.3);                  // false
System.out.println(Math.abs(d - 0.3) < 1e-9);  // true（差が十分小さいか）
```

## ポイント

- 比較式の結果は `boolean`（true / false）
- 「以上・以下」は境界を含む。境界値は必ずテストする
- 文字列は `equals`、小数は差の大きさで比べる

## Option：等しいと同じものは別

値の等しさとオブジェクトの同一性は区別します。Javaの配列はequalsを呼ぶだけでは要素ごとの比較にならないため、必要ならArrays.equals等を使います。

**やってみよう：** 同じ内容のint配列を2つ作り、==、equals、Arrays.equalsの結果を比べてみましょう。
