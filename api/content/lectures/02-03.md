## まずはここから

別のネットワークへ情報を届けるには、途中で進む道を選びます。この道案内がルーティングです。手紙を途中の拠点へ渡し、宛先まで運ぶ場面を想像しましょう。

### 最初に覚える4つの言葉

#### ルーティング

通信の次の行き先を選ぶこと。

**具体例：** 遠くのサーバーへ進む経路を選ぶ。

#### ルーター

ネットワーク間でデータを中継する機器。

**具体例：** 家庭内から外のネットワークへつなぐ。

#### 経路表

宛先ごとの行き先を記録した情報。

**具体例：** この宛先ならこの出口と判断する。

#### デフォルトゲートウェイ

より具体的な経路がない時の主な出口。

**具体例：** 外部宛の通信を所定のルーターへ渡す。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## ルーティングとは

データ（パケット）を、宛先までどの経路で届けるかを決めることです。インターネットは無数のネットワークがつながったもので、パケットは **ルーター** を次々に中継されて宛先に届きます。

## ルーターとルーティングテーブル

ルーターは、**ルーティングテーブル**（経路表）を見て、パケットを次にどこへ渡すかを決めます。

| 宛先ネットワーク | 次の中継先（ネクストホップ） | 出口 |
|---|---|---|
| 192.168.1.0/24 | 直接つながっている | LAN 側 |
| 10.0.0.0/8 | 192.168.1.254 | LAN 側 |
| 0.0.0.0/0（それ以外すべて） | プロバイダーのルーター | WAN 側 |

- 宛先に一番 **詳しく一致する**（プレフィックスが長い）経路を選ぶ
- どれにも当てはまらない宛先は、**デフォルトルート**（`0.0.0.0/0`）に送る

## デフォルトゲートウェイ

PC から見て、「自分のネットワークの外宛ての通信を最初に渡すルーター」です。PC は、宛先が同じネットワークなら直接送り、違えばデフォルトゲートウェイに送ります。

```text
PC（192.168.1.10/24）
  宛先 192.168.1.20 → 同じネットワークなので直接送る
  宛先 8.8.8.8      → 違うネットワークなのでデフォルトゲートウェイ（192.168.1.1）へ
```

デフォルトゲートウェイの設定が誤っていると、社内の同じネットワークとは通信できるのに、インターネットにはつながらない、という症状になります。

## 静的ルーティングと動的ルーティング

| 方式 | 内容 | 向いている場面 |
|---|---|---|
| 静的ルーティング | 管理者が経路を手で設定する | 小規模で、構成が変わらないネットワーク |
| 動的ルーティング | ルーターどうしが情報を交換して、経路を自動で作る | 大規模なネットワーク、障害時に経路を切り替えたいとき |

動的ルーティングのプロトコルには、社内向けの OSPF、インターネットの組織間をつなぐ BGP などがあります。

## NAT

社内のプライベート IP アドレスを、ルーターがグローバル IP アドレスに変換して、インターネットと通信できるようにする仕組みです。ポート番号も使って変換する方式（NAPT、IP マスカレード）により、1 つのグローバル IP アドレスを多数の機器で共有できます。

## 経路を確認する

```text
tracert example.com      （Windows）
traceroute example.com   （Linux / macOS）
```

宛先までに通過するルーターが順に表示されます。どこで止まっているかで、障害の場所を絞り込めます。

自分の PC のルーティングテーブルは、Windows では `route print` で確認できます。

## ポイント

- パケットはルーターがルーティングテーブルを見て中継する
- 外部宛ての通信は、まずデフォルトゲートウェイへ
- NAT でプライベート IP アドレスとグローバル IP アドレスを変換する
- `tracert` で経路と障害の場所を確かめられる

## Option：往路だけでなく復路も見る

要求がサーバーに届いても、返答の経路や制御に問題があると通信は成立しません。複数のネットワーク機器を経由する構成では、戻りの経路と接続状態の扱いも重要です。

**やってみよう：** PC→ルーター→サーバーの矢印を往復で描き、それぞれの経路表と制御点を考えてみましょう。
