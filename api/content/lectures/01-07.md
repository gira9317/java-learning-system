## 算術演算とは

足し算・引き算などの計算を行う演算です。計算に使う記号を **演算子**、計算される値を **オペランド** といいます。

| 演算子 | 意味 | 例 | 結果 |
|---|---|---|---|
| `+` | 足し算 | `7 + 2` | 9 |
| `-` | 引き算 | `7 - 2` | 5 |
| `*` | かけ算 | `7 * 2` | 14 |
| `/` | 割り算 | `7 / 2` | 3（整数どうし） |
| `%` | 割り算の余り | `7 % 2` | 1 |

## 整数どうしの割り算

Java では、整数どうしの割り算は **小数点以下が切り捨て** られます（0 に近い方向へ）。

```java
System.out.println(7 / 2);    // 3
System.out.println(-7 / 2);   // -3
System.out.println(7 / 2.0);  // 3.5（どちらかが小数なら小数の計算）
System.out.println((double) 7 / 2); // 3.5
```

整数を 0 で割ると `ArithmeticException` が発生します。

## 余り（%）の使いどころ

- 偶数・奇数の判定: `n % 2 == 0` なら偶数
- 一定間隔の処理: `i % 10 == 0` のときだけ処理する
- 桁の取り出し: `1234 % 10` は 4（一の位）

## 優先順位

かけ算・割り算・余りは、足し算・引き算より先に計算されます。迷ったら括弧を付けます。

```java
int a = 2 + 3 * 4;   // 14
int b = (2 + 3) * 4; // 20
```

## 代入演算子とインクリメント

```java
int x = 10;
x += 5;  // x = x + 5  → 15
x -= 3;  // x = x - 3  → 12
x *= 2;  // x = x * 2  → 24
x /= 4;  // x = x / 4  → 6
x %= 4;  // x = x % 4  → 2

x++;     // 1 増やす → 3
x--;     // 1 減らす → 2
```

`x++`（後置）と `++x`（前置）は、式の中で使うと値が変わるタイミングが違います。

```java
int i = 5;
int a = i++; // a は 5、そのあと i は 6
int b = ++i; // i が 7 になってから、b は 7
```

混乱しやすいので、式の中では使わず、単独の文として書くのがおすすめです。

## 文字列の連結

`+` は、片方が文字列なら **連結** になります。左から順に評価される点に注意します。

```java
System.out.println("合計: " + 1 + 2);   // 合計: 12
System.out.println("合計: " + (1 + 2)); // 合計: 3
```

## ポイント

- 整数どうしの `/` は切り捨て。小数が欲しければどちらかを `double` にする
- `%` は偶奇判定や周期的な処理に便利
- 優先順位に迷ったら括弧を付ける

> **確認しよう**
>
> - `17 / 5` と `17 % 5` の結果はそれぞれいくつでしょうか。
> - 秒数 `3725` を「1 時間 2 分 5 秒」に分ける計算を、`/` と `%` で書いてみましょう。
