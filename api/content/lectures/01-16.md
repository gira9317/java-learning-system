## まずはここから

データは、入れた順に取り出す場合と、最後に入れたものから取り出す場合があります。レジの行列と、上からお皿を積む場面を思い浮かべてください。この順番の違いを学びます。

### 最初に覚える4つの言葉

#### スタック

最後に入れたものから取り出す仕組み。

**具体例：** 積んだお皿の一番上から取る。

#### キュー

先に入れたものから取り出す仕組み。

**具体例：** レジへ先に並んだ人から進む。

#### push

スタックへデータを入れる操作。

**具体例：** お皿を山の一番上へ置く。

#### pop

スタックからデータを取り出す操作。

**具体例：** 一番上のお皿を1枚取る。

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## データ構造とは

データを **どのように並べて持つか** の決まりです。用途に合ったデータ構造を選ぶと、処理が簡単に、速くなります。代表的なものに、配列・リスト・スタック・キュー・木・ハッシュ表があります。

## スタック（後入れ先出し）

最後に入れたものから順に取り出す構造です。**LIFO**（Last In, First Out）といいます。積み重ねた本を上から取るイメージです。

| 操作 | 内容 |
|---|---|
| push | 一番上に積む |
| pop | 一番上から取り出す |
| peek | 一番上を見る（取り出さない） |

```text
push(1) push(2) push(3)  →  [1, 2, 3]  ← 上
pop() → 3、pop() → 2
```

使われている場面:

- ブラウザの「戻る」ボタン（直前に見たページから戻る）
- エディタの「元に戻す（Undo）」
- メソッド呼び出しの管理（コールスタック）。再帰が深すぎると `StackOverflowError` になる
- 括弧の対応チェック

## キュー（先入れ先出し）

最初に入れたものから順に取り出す構造です。**FIFO**（First In, First Out）といいます。レジの行列のイメージです。

| 操作 | 内容 |
|---|---|
| enqueue（offer） | 末尾に並べる |
| dequeue（poll） | 先頭から取り出す |
| peek | 先頭を見る |

使われている場面:

- プリンターの印刷待ち
- Web サーバーへのリクエストの処理待ち
- メッセージキュー（システム間で処理を順番に受け渡す）

## Java での使い方

Java では、どちらも `ArrayDeque` で表せます。

```java
import java.util.ArrayDeque;
import java.util.Deque;

// スタック
Deque<String> stack = new ArrayDeque<>();
stack.push("A");
stack.push("B");
System.out.println(stack.pop()); // B

// キュー
Deque<String> queue = new ArrayDeque<>();
queue.offer("A");
queue.offer("B");
System.out.println(queue.poll()); // A
```

（古い `Stack` クラスもありますが、現在は `ArrayDeque` が推奨されています。）

## 括弧の対応をスタックで調べる

```java
static boolean balanced(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') stack.push(c);
        else if (c == ')') {
            if (stack.isEmpty()) return false;
            stack.pop();
        }
    }
    return stack.isEmpty();
}
```

## ポイント

- スタックは後入れ先出し（LIFO）、キューは先入れ先出し（FIFO）
- 「直前に戻る」ならスタック、「来た順に処理する」ならキュー
- Java ではどちらも `ArrayDeque` を使う

### 問5【応用】

スタックへA、次にBを入れ、1つ取り出すと？

#### 選択肢

- A. Aが取り出される
- B. 何も出ない
- C. Bが取り出される
- D. 必ず両方が出る

#### 解答・解説

正解: C

スタックは最後に入れたものが先です。キューとは逆になります。

## Option：幅優先探索と深さ優先探索

キューで未処理の要素を管理すると近い場所から順に調べる幅優先探索に、スタックを使うと奥へ進む深さ優先探索に応用できます。訪問済みの管理を忘れると、循環するデータで終わらなくなります。

**やってみよう：** 小さな迷路で、キューとスタックによる探索順の違いを紙に描いてみましょう。
