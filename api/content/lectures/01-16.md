## データ構造とは

データを **どのように並べて持つか** の決まりです。用途に合ったデータ構造を選ぶと、処理が簡単に、速くなります。代表的なものに、配列・リスト・スタック・キュー・木・ハッシュ表があります。

## スタック（後入れ先出し）

最後に入れたものから順に取り出す構造です。**LIFO**（Last In, First Out）といいます。積み重ねた本を上から取るイメージです。

| 操作 | 内容 |
|---|---|
| push | 一番上に積む |
| pop | 一番上から取り出す |
| peek | 一番上を見る（取り出さない） |

```text
push(1) push(2) push(3)  →  [1, 2, 3]  ← 上
pop() → 3、pop() → 2
```

使われている場面:

- ブラウザの「戻る」ボタン（直前に見たページから戻る）
- エディタの「元に戻す（Undo）」
- メソッド呼び出しの管理（コールスタック）。再帰が深すぎると `StackOverflowError` になる
- 括弧の対応チェック

## キュー（先入れ先出し）

最初に入れたものから順に取り出す構造です。**FIFO**（First In, First Out）といいます。レジの行列のイメージです。

| 操作 | 内容 |
|---|---|
| enqueue（offer） | 末尾に並べる |
| dequeue（poll） | 先頭から取り出す |
| peek | 先頭を見る |

使われている場面:

- プリンターの印刷待ち
- Web サーバーへのリクエストの処理待ち
- メッセージキュー（システム間で処理を順番に受け渡す）

## Java での使い方

Java では、どちらも `ArrayDeque` で表せます。

```java
import java.util.ArrayDeque;
import java.util.Deque;

// スタック
Deque<String> stack = new ArrayDeque<>();
stack.push("A");
stack.push("B");
System.out.println(stack.pop()); // B

// キュー
Deque<String> queue = new ArrayDeque<>();
queue.offer("A");
queue.offer("B");
System.out.println(queue.poll()); // A
```

（古い `Stack` クラスもありますが、現在は `ArrayDeque` が推奨されています。）

## 括弧の対応をスタックで調べる

```java
static boolean balanced(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') stack.push(c);
        else if (c == ')') {
            if (stack.isEmpty()) return false;
            stack.pop();
        }
    }
    return stack.isEmpty();
}
```

## ポイント

- スタックは後入れ先出し（LIFO）、キューは先入れ先出し（FIFO）
- 「直前に戻る」ならスタック、「来た順に処理する」ならキュー
- Java ではどちらも `ArrayDeque` を使う

> **確認しよう**
>
> - 空のスタックに push(1), push(2), pop(), push(3), pop() をすると、最後に残るのは何でしょうか。
> - 同じ操作（push を enqueue、pop を dequeue に置き換え）をキューで行うとどうなるでしょうか。
