## まずはここから

数そのものを扱う場合と、データの集まりを『どこにあるか』という情報で扱う場合があります。参照は、その集まりへたどり着くための情報です。最初は『値のコピー』と『同じ物を見ている』の違いだけ意識しましょう。

### 最初に覚える4つの言葉

#### プリミティブ型

整数などの基本的な値を扱う型。

**具体例：** intで人数の3を扱う。

#### 参照型

オブジェクトへの参照を扱う型。

**具体例：** 配列や文字列を使う。

#### null

参照先がないことを表す値。

**具体例：** まだ対象が設定されていない状態を表す。

#### 配列

同じ型の複数の値をまとめるもの。

**具体例：** 3人の点数をひとまとめにする。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## 2 種類の型

Java の型は、大きく 2 つに分かれます。

| 種類 | 変数に入っているもの | 例 |
|---|---|---|
| プリミティブ型（基本データ型） | **値そのもの** | `int`、`double`、`boolean`、`char` など 8 種類 |
| 参照型 | オブジェクトの **場所（参照）** | `String`、配列、クラス、`List` など |

## 代入したときの違い

プリミティブ型は **値がコピー** されます。

```java
int a = 10;
int b = a;   // 10 がコピーされる
b = 20;
System.out.println(a); // 10（a は変わらない）
```

参照型は **参照（場所）がコピー** され、同じオブジェクトを指します。

```java
int[] x = {1, 2, 3};
int[] y = x;   // 同じ配列を指す
y[0] = 99;
System.out.println(x[0]); // 99（x から見ても変わっている）
```

```text
x ─┐
   ├──→ [99, 2, 3]
y ─┘
```

## メソッドに渡したとき

Java は常に **値渡し** です。参照型の場合は「参照という値」が渡されるため、メソッドの中でオブジェクトの中身を変えると、呼び出し元からも変わって見えます。

```java
static void change(int n, int[] arr) {
    n = 100;        // 呼び出し元の変数は変わらない
    arr[0] = 100;   // 同じ配列を指しているので、呼び出し元から見ても変わる
}
```

## null

参照型の変数には、「何も指していない」ことを表す `null` を入れられます。`null` の変数のメソッドを呼ぶと、`NullPointerException` が発生します。

```java
String s = null;
s.length(); // NullPointerException
```

プリミティブ型には `null` を入れられません。

## 比較の違い

- プリミティブ型の `==` は **値** を比べる
- 参照型の `==` は **同じオブジェクトかどうか** を比べる。中身を比べるには `equals`

## ラッパークラス

プリミティブ型を参照型として扱うためのクラスです。`List` などは参照型しか入れられないため、`List<int>` ではなく `List<Integer>` と書きます。

| プリミティブ型 | ラッパークラス |
|---|---|
| `int` | `Integer` |
| `double` | `Double` |
| `boolean` | `Boolean` |
| `char` | `Character` |

Java は必要に応じて自動で変換します（オートボクシング・アンボクシング）。ただし、`null` の `Integer` を `int` に変換しようとすると `NullPointerException` になります。

## ポイント

- プリミティブ型は値、参照型は場所を持つ
- 参照型を代入・引数で渡すと、同じオブジェクトを共有する
- 参照型の中身の比較は `equals`、`null` に注意する

## Option：浅いコピーと深いコピー

配列やリストの外側だけを複製しても、中の可変オブジェクトは共有される場合があります。どこまで独立させる必要があるかを決めずにコピーすると、想定外の変更が伝わります。

**やってみよう：** 要素が可変オブジェクトのリストを複製し、要素の変更と要素の入れ替えの影響を比べてみましょう。
