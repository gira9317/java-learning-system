## 論理演算とは

真（true）と偽（false）を組み合わせて、新しい真偽値を作る演算です。複数の条件をまとめるときに使います。

| 演算 | Java | 意味 |
|---|---|---|
| 論理積（AND） | `&&` | 両方が真なら真 |
| 論理和（OR） | `\|\|` | どちらかが真なら真 |
| 否定（NOT） | `!` | 真と偽を反転する |

## 真理値表

| A | B | A && B | A \|\| B | !A |
|---|---|---|---|---|
| true | true | true | true | false |
| true | false | false | true | false |
| false | true | false | true | true |
| false | false | false | false | true |

## 使い方の例

```java
int age = 25;
boolean member = true;

// 20 歳以上 かつ 会員
if (age >= 20 && member) { ... }

// 土曜 または 日曜
if (day.equals("土") || day.equals("日")) { ... }

// 会員でない
if (!member) { ... }
```

範囲の判定は、`&&` で 2 つの比較をつなぎます。数学のように `0 <= x <= 100` とは書けません。

```java
if (0 <= x && x <= 100) { ... }
```

## 短絡評価（ショートサーキット）

`&&` は左が偽なら、`||` は左が真なら、**右側を評価しません**。結果が確定しているからです。これを利用すると、エラーを防げます。

```java
// name が null のときは、右の name.isEmpty() を実行しない
if (name != null && !name.isEmpty()) { ... }
```

順番を逆にすると、`name` が `null` のときに `NullPointerException` が発生します。

## ド・モルガンの法則

否定を分配するときは、AND と OR が入れ替わります。

- `!(A && B)` は `!A || !B` と同じ
- `!(A || B)` は `!A && !B` と同じ

```java
// 「0 以上 100 以下」ではない
!(0 <= x && x <= 100)
// は、次と同じ
x < 0 || 100 < x
```

条件を読みやすく書き直すときに役立ちます。

## ポイント

- `&&` は両方、`||` はどちらか、`!` は反転
- 範囲は `a <= x && x <= b` と書く
- 短絡評価を利用して、null チェックを先に書く
- 否定を外すと AND と OR が入れ替わる

> **確認しよう**
>
> - 「平日 かつ 9 時以上 18 時未満」を、`weekday`（boolean）と `hour`（int）で書いてみましょう。
> - `!(score >= 60 || retry)` を、`!` を使わない形に書き直してみましょう。
