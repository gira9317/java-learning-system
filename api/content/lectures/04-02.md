## SQL とは

RDB を操作するための言語です。どの RDB 製品でも、基本的な書き方は共通です（細かい機能は製品ごとに違います）。

| 分類 | 内容 | 主な命令 |
|---|---|---|
| DDL（定義） | 表などを作る・変える・消す | `CREATE`、`ALTER`、`DROP` |
| DML（操作） | データを検索・追加・更新・削除する | `SELECT`、`INSERT`、`UPDATE`、`DELETE` |
| DCL（制御） | 権限やトランザクションを扱う | `GRANT`、`REVOKE`、`COMMIT`、`ROLLBACK` |

## 表を作る

```sql
CREATE TABLE employees (
  id       integer      PRIMARY KEY,
  name     varchar(50)  NOT NULL,
  dept_id  integer      REFERENCES departments(id),
  salary   integer      NOT NULL CHECK (salary >= 0),
  hired_on date         NOT NULL
);
```

## データを追加・更新・削除する

```sql
INSERT INTO employees (id, name, dept_id, salary, hired_on)
VALUES (1, '山田', 10, 250000, '2026-04-01');

UPDATE employees
SET salary = 260000
WHERE id = 1;

DELETE FROM employees
WHERE id = 1;
```

**`UPDATE` と `DELETE` で `WHERE` を忘れると、すべての行が変更・削除されます**。実行する前に、同じ条件の `SELECT` で対象を確かめる習慣をつけます。

## データを検索する（SELECT）

```sql
SELECT name, salary          -- 取り出す列
FROM employees               -- 対象の表
WHERE dept_id = 10           -- 行の条件
  AND salary >= 200000
ORDER BY salary DESC         -- 並べ替え（DESC は降順）
LIMIT 10;                    -- 件数の上限
```

書く順番と、実際に処理される順番は違います。

```text
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT
```

## 条件の書き方

| 書き方 | 意味 |
|---|---|
| `=`、`<>`、`>`、`>=`、`<`、`<=` | 比較 |
| `AND`、`OR`、`NOT` | 組み合わせ |
| `BETWEEN 200000 AND 300000` | 範囲（両端を含む） |
| `IN (10, 20)` | いずれかに等しい |
| `LIKE '山%'` | 前方一致（`%` は任意の文字列、`_` は任意の 1 文字） |
| `IS NULL` / `IS NOT NULL` | 空かどうか（`= NULL` とは書かない） |

## 集計する

```sql
-- 部署ごとの人数と平均給与（平均が 25 万円以上の部署だけ）
SELECT dept_id, COUNT(*) AS members, AVG(salary) AS avg_salary
FROM employees
GROUP BY dept_id
HAVING AVG(salary) >= 250000;
```

| 関数 | 内容 |
|---|---|
| `COUNT(*)` | 件数 |
| `SUM(列)` | 合計 |
| `AVG(列)` | 平均 |
| `MAX(列)` / `MIN(列)` | 最大 / 最小 |

- `WHERE` は **集計前の行** の条件、`HAVING` は **集計後のグループ** の条件
- `GROUP BY` を使うとき、`SELECT` に書けるのは、`GROUP BY` の列と集計関数だけ

## NULL の扱い

`NULL` は「値がない・わからない」ことを表し、0 や空文字とは違います。

- `NULL` との比較（`=`、`<>`）は、真でも偽でもなく「不明」になる
- `COUNT(列)` は `NULL` を数えない（`COUNT(*)` は数える）
- `COALESCE(列, 0)` で、`NULL` のときの代わりの値を指定できる

## Java から SQL を実行する

```java
String sql = "SELECT name FROM employees WHERE dept_id = ?";
try (PreparedStatement ps = conn.prepareStatement(sql)) {
    ps.setInt(1, deptId);   // ? に値を安全に入れる
    try (ResultSet rs = ps.executeQuery()) {
        while (rs.next()) {
            System.out.println(rs.getString("name"));
        }
    }
}
```

値は文字列の連結で SQL に埋め込まず、**必ず `?`（プレースホルダー）** を使います（第 5 章「SQL インジェクション」）。

## ポイント

- SELECT は FROM・WHERE・GROUP BY・HAVING・ORDER BY の組み合わせ
- UPDATE / DELETE は WHERE を忘れない。先に SELECT で確かめる
- WHERE は集計前、HAVING は集計後
- NULL は `IS NULL` で調べる
- Java からはプレースホルダーを使う
