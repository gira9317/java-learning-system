## 順次処理とは

命令を **上から順番に 1 つずつ** 実行する、もっとも基本的な処理の流れです。プログラムの流れは、次の 3 つの組み合わせで表せます（構造化プログラミング）。

| 構造 | 内容 |
|---|---|
| 順次 | 上から順に実行する |
| 分岐（選択） | 条件によって実行する処理を変える |
| 反復（繰り返し） | 条件を満たす間、同じ処理を繰り返す |

どんなに複雑なプログラムも、この 3 つを組み合わせて作られています。

## フローチャートでの表し方

| 記号 | 意味 |
|---|---|
| 角丸の長方形（端子） | 開始・終了 |
| 長方形 | 処理 |
| 平行四辺形 | データの入力・出力 |
| ひし形 | 条件による分岐 |

順次処理は、処理の箱を矢印で上から下へつなぐだけです。

```text
 [開始]
   ↓
 /単価と個数を入力/
   ↓
 [金額 = 単価 × 個数]
   ↓
 [税込 = 金額 × 1.1]
   ↓
 /税込を表示/
   ↓
 [終了]
```

## Java で書くと

```java
int price = 1200;                 // 単価
int quantity = 3;                 // 個数
int amount = price * quantity;    // 金額
int total = (int) (amount * 1.1); // 税込（切り捨て）
System.out.println(total);        // 3960
```

## 順番が大切

順次処理では、**順番を入れ替えると結果が変わる** ことがあります。

```java
int a = 5;
int b = 3;

// a と b を入れ替えたい（誤り）
a = b;   // a は 3
b = a;   // b も 3 になってしまう

// 正しくは、一時的な変数を使う
int tmp = a;
a = b;
b = tmp;
```

値を使う前に、その値が正しく用意されているかを意識します。

## ポイント

- プログラムは「順次・分岐・反復」の組み合わせでできている
- 順次処理は上から下へ 1 つずつ実行される
- 処理の順番を変えると結果が変わることがある

> **確認しよう**
>
> - 「体重（kg）と身長（m）を入力し、BMI = 体重 ÷ 身長² を表示する」処理をフローチャートにしてみましょう。
> - 3 つの変数 a, b, c の値を「a←b、b←c、c←a」と回す手順を書いてみましょう。
