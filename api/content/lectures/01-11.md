## まずはここから

プログラムは、基本的に書かれた順に仕事をします。レシピの『材料を切る→炒める→盛り付ける』と同じです。まずは1行ごとに何が起きるかを追えれば十分です。

### 最初に覚える4つの言葉

#### 順次処理

処理を順番に実行すること。

**具体例：** 入力してから計算し、最後に表示する。

#### 入力

処理に使う情報を受け取ること。

**具体例：** 体重を入力する。

#### 出力

処理の結果などを外へ出すこと。

**具体例：** 計算した結果を画面に表示する。

#### 代入

変数へ値を入れること。

**具体例：** x=3でxの値を3にする。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## 順次処理とは

命令を **上から順番に 1 つずつ** 実行する、もっとも基本的な処理の流れです。プログラムの流れは、次の 3 つの組み合わせで表せます（構造化プログラミング）。

| 構造 | 内容 |
|---|---|
| 順次 | 上から順に実行する |
| 分岐（選択） | 条件によって実行する処理を変える |
| 反復（繰り返し） | 条件を満たす間、同じ処理を繰り返す |

どんなに複雑なプログラムも、この 3 つを組み合わせて作られています。

## フローチャートでの表し方

| 記号 | 意味 |
|---|---|
| 角丸の長方形（端子） | 開始・終了 |
| 長方形 | 処理 |
| 平行四辺形 | データの入力・出力 |
| ひし形 | 条件による分岐 |

順次処理は、処理の箱を矢印で上から下へつなぐだけです。

```text
 [開始]
   ↓
 /単価と個数を入力/
   ↓
 [金額 = 単価 × 個数]
   ↓
 [税込 = 金額 × 1.1]
   ↓
 /税込を表示/
   ↓
 [終了]
```

## Java で書くと

```java
int price = 1200;                 // 単価
int quantity = 3;                 // 個数
int amount = price * quantity;    // 金額
int total = (int) (amount * 1.1); // 税込（切り捨て）
System.out.println(total);        // 3960
```

## 順番が大切

順次処理では、**順番を入れ替えると結果が変わる** ことがあります。

```java
int a = 5;
int b = 3;

// a と b を入れ替えたい（誤り）
a = b;   // a は 3
b = a;   // b も 3 になってしまう

// 正しくは、一時的な変数を使う
int tmp = a;
a = b;
b = tmp;
```

値を使う前に、その値が正しく用意されているかを意識します。

## ポイント

- プログラムは「順次・分岐・反復」の組み合わせでできている
- 順次処理は上から下へ 1 つずつ実行される
- 処理の順番を変えると結果が変わることがある

### 問5【応用】

x=2の次にx=x+1を実行した後のxは？

#### 選択肢

- A. 3
- B. 1
- C. 無限に増え続ける
- D. 2

#### 解答・解説

正解: A

その行では今のxに1を足した結果を、xへ1回だけ代入します。

## Option：順番の依存関係を見つける

処理の順番を入れ替えられるかは、読み書きするデータの依存関係で決まります。同じ変数を更新する処理は、並列化すると結果が変わることもあります。

**やってみよう：** 料理の手順を、順番が必須な処理と並行できる処理に分けてみましょう。
