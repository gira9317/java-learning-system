## C 言語とは

1972 年ごろに生まれた、歴史の長い言語です。OS（Linux や Windows の中核）、組み込み機器、ほかの言語の実行環境（Python の標準実装など）が C で書かれています。Java の文法の多くは C の影響を受けています。

| 特徴 | 内容 |
|---|---|
| 速い | 機械語に直接コンパイルされ、無駄が少ない |
| ハードウェアに近い | メモリをアドレスで直接扱える |
| 自己責任 | メモリの確保と解放をプログラマーが行う。間違いはそのまま不具合や脆弱性になる |

## はじめてのプログラム

```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
```

## Java と似ているところ

変数の型、演算子、`if`、`for`、`while`、`switch` の書き方はほぼ同じです。

```c
int sum = 0;
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        sum += i;
    }
}
printf("%d\n", sum); // 30
```

## Java と違うところ

| 項目 | C | Java |
|---|---|---|
| オブジェクト指向 | ない（構造体 `struct` でデータをまとめる） | クラス |
| 文字列 | `char` の配列。末尾に `'\0'` が必要 | `String` クラス |
| 真偽値 | 0 が偽、0 以外が真 | `boolean` |
| メモリ管理 | `malloc` で確保、`free` で解放 | GC が自動で回収 |
| 配列の範囲 | チェックしない（範囲外を書き換えてしまう） | 範囲外で例外 |
| 例外 | ない（戻り値でエラーを返す） | `try` / `catch` |

## ポインタ

変数の **メモリ上の場所（アドレス）** を入れる変数です。

```c
int x = 10;
int *p = &x;    // p に x のアドレスを入れる
*p = 20;        // p が指す先（x）を書き換える
printf("%d\n", x); // 20
```

- `&x`: x のアドレス
- `*p`: p が指す先の値

Java の参照型は、ポインタを安全に使えるようにしたものと考えられます（アドレスの計算はできない）。

## メモリの確保と解放

```c
#include <stdlib.h>

int *nums = malloc(sizeof(int) * 5);   // int 5 個分を確保
if (nums == NULL) { return 1; }        // 確保に失敗した場合
for (int i = 0; i < 5; i++) nums[i] = i * 10;
free(nums);                            // 使い終わったら必ず解放
```

解放し忘れると **メモリリーク**、解放したあとに使うと予測できない不具合になります。配列の範囲外への書き込み（**バッファオーバーフロー**）は、攻撃に悪用される代表的な脆弱性です。

## ポイント

- C は速くハードウェアに近いが、メモリの安全はプログラマーの責任
- 基本の文法は Java とよく似ている
- ポインタはメモリのアドレスを扱う
- Java の GC や配列の範囲チェックが、何を守ってくれているかがわかる

> **確認しよう**
>
> - C で配列の範囲外に書き込んだとき、Java と比べて何が危険でしょうか。
> - `int *p = &x; *p = *p + 1;` のあと、`x` はどうなるでしょうか。
