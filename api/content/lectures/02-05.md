## まずはここから

ネットワーク機器は、機械同士をつないだり別の場所へ中継したりする道具です。どれも同じ箱に見えても、役割が違います。まずは近くの機器をつなぐ役と、別のネットワークへ渡す役を分けましょう。

### 最初に覚える4つの言葉

#### スイッチ

同じネットワーク内の機器等を中継する機器。

**具体例：** 部署内のPCを有線でつなぐ。

#### ルーター

異なるネットワーク間を中継する機器。

**具体例：** 社内から外部へ通信を渡す。

#### アクセスポイント

無線LANの端末を接続する機器。

**具体例：** ノートPCをWi-Fiでつなぐ。

#### MACアドレス

主に同じリンク上の配送で使う識別情報。

**具体例：** 接続先の機器をリンク上で区別する。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## ネットワーク機器の役割

ネットワークは、役割の違う機器を組み合わせて作ります。どの機器が OSI 参照モデルの **どの層の情報を見て動くか** を押さえると、違いがわかりやすくなります。

| 機器 | 層 | 見る情報 | 役割 |
|---|---|---|---|
| リピーターハブ | 1 物理層 | 電気信号 | 受けた信号を、すべてのポートにそのまま流す（現在はほぼ使われない） |
| スイッチ（L2 スイッチ） | 2 データリンク層 | MAC アドレス | 同じネットワーク内で、宛先の機器がつながるポートにだけ転送する |
| ルーター | 3 ネットワーク層 | IP アドレス | 異なるネットワークの間でパケットを中継する |
| L3 スイッチ | 3 ネットワーク層 | IP アドレス | スイッチにルーティング機能を持たせたもの。社内 LAN の中で高速に中継する |
| ファイアウォール | 3〜7 層 | IP・ポート・通信の中身 | 通信を許可・拒否する |
| ロードバランサー | 4〜7 層 | ポート・HTTP の中身 | 複数のサーバーにアクセスを振り分ける |

## MAC アドレス

ネットワーク機器（LAN カードなど）に、製造時に割り当てられる 48 ビットの番号です。`00-1A-2B-3C-4D-5E` のように 16 進数で書きます。

- **MAC アドレス**: 同じネットワーク内で、隣の機器を識別する
- **IP アドレス**: ネットワークをまたいで、最終的な宛先を識別する

IP アドレスから MAC アドレスを調べる仕組みを **ARP** といいます。

## スイッチの働き

スイッチは、「どのポートに、どの MAC アドレスの機器がつながっているか」を学習して表（MAC アドレステーブル）にし、宛先のポートにだけ転送します。ほかの機器に余計な通信が流れないため、効率がよく、盗み見もされにくくなります。

### VLAN

1 台のスイッチを、論理的に複数のネットワークに分ける機能です。部署ごとにネットワークを分けたいときなどに使います。

## 無線 LAN の機器

| 機器 | 役割 |
|---|---|
| アクセスポイント | 無線の端末を有線のネットワークにつなぐ |
| 無線 LAN ルーター | アクセスポイント・ルーター・スイッチなどを 1 台にまとめた家庭向けの機器 |

無線は電波で届く範囲なら誰でも受信できるため、WPA2 / WPA3 で暗号化します。

## サーバー側の機器の例

```text
インターネット
   │
ファイアウォール
   │
ロードバランサー ── Web サーバー 1
                 └─ Web サーバー 2
                         │
                    DB サーバー
```

- **ロードバランサー**: アクセスを複数の Web サーバーに分け、1 台が止まってもサービスを続けられるようにする
- **プロキシサーバー**: 社員の PC の代わりに外部へアクセスし、閲覧の制限や記録を行う

## ポイント

- スイッチは MAC アドレス（2 層）、ルーターは IP アドレス（3 層）を見る
- 同じネットワーク内はスイッチ、ネットワーク間はルーター
- ロードバランサーで負荷を分散し、障害に備える

## Option：機器名より処理の位置を見る

1台の装置がスイッチ、ルーター、ファイアウォールを兼ねる場合もあります。故障調査や構成図では、商品名ではなくどの通信をどこで分離・転送・制御しているかを記録しましょう。

**やってみよう：** 自宅や検証環境の機器を、無線接続・経路選択・通信制御の役割に分けて描いてみましょう。
