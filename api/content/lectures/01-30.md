## まずはここから

Pythonもコンピューターへの指示を書く言語です。行の先頭の空白で処理のまとまりを表す特徴があります。まずは短い表示や計算を実行し、Javaとの違いを少しずつ見ましょう。

### 最初に覚える4つの言葉

#### print

値を表示するPythonの機能。

**具体例：** printでこんにちはを出す。

#### インデント

行の先頭の字下げ。

**具体例：** ifの中の処理を空白でそろえる。

#### リスト

複数の値を順にまとめるもの。

**具体例：** 名前をいくつも並べて覚える。

#### 辞書

キーと値を組にして扱うもの。

**具体例：** 名前というキーから太郎を取り出す。

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## Python とは

読みやすさを重視した言語です。少ないコードで書け、ライブラリが豊富なため、データ分析、機械学習・AI、業務の自動化、Web 開発などで広く使われています。

| 特徴 | 内容 |
|---|---|
| インタープリター | コンパイル不要で、すぐ実行できる |
| 動的型付け | 変数の型を宣言しない |
| インデントで構造を表す | `{ }` の代わりに字下げでブロックを表す |
| ライブラリが豊富 | pandas、NumPy、requests など |

## 基本の書き方（Java との比較）

```python
# 変数（型は書かない）
name = "山田"
age = 25
height = 170.5
passed = True          # True / False は先頭が大文字

# 分岐（インデントが必須）
if age >= 20:
    print("成人")
elif age >= 13:
    print("10 代")
else:
    print("子ども")

# 繰り返し
for i in range(1, 6):   # 1〜5
    print(i)

total = 0
while total < 100:
    total += 10
```

| 項目 | Python | Java |
|---|---|---|
| ブロック | インデント | `{ }` |
| 文の終わり | 改行 | `;` |
| 論理演算 | `and` `or` `not` | `&&` `\|\|` `!` |
| 割り算 | `7 / 2` は 3.5、`7 // 2` は 3 | 整数どうしは 3 |
| null | `None` | `null` |

## リストと辞書

```python
scores = [80, 55, 92]          # リスト（Java の List）
scores.append(70)
print(len(scores), sum(scores), max(scores))

member = {"name": "山田", "age": 25}   # 辞書（Java の Map）
print(member["name"])

# 内包表記: 条件に合うものだけを集める
passed = [s for s in scores if s >= 60]   # [80, 92, 70]
```

## 関数

```python
def add(a, b):
    return a + b

print(add(3, 4))  # 7
```

型ヒントを付けると、エディタやチェックツールが間違いを見つけやすくなります。

```python
def add(a: int, b: int) -> int:
    return a + b
```

## Python が向いている場面

- CSV や Excel のデータを集計・変換する
- 定型作業を自動化するスクリプト
- データ分析、グラフ作成、機械学習

業務システム本体は Java、周辺のちょっとした自動化は Python、といった使い分けもよく見られます。

## ポイント

- インデントがそのまま構造になる
- 型を書かずに短く書けるが、間違いは実行するまでわからない
- リスト・辞書・内包表記でデータを手軽に扱える

## Option：短いコードと読みやすいコード
