## まずはここから

通信では、どの相手へ届けるかと、その相手のどのサービスへ届けるかを区別します。建物の住所と窓口の番号を分けるイメージです。IPアドレスとポート番号を、この2つへ対応させてみましょう。

### 最初に覚える4つの言葉

#### IPアドレス

ネットワーク上の宛先を表す番号。

**具体例：** サーバーの宛先を指定する。

#### ポート番号

相手のどの通信窓口かを表す番号。

**具体例：** 3000番で待つWebサーバーへつなぐ。

#### localhost

自分の実行環境を指す名前。

**具体例：** 自分のPCで動くサーバーを開く。

#### TCP

順序や再送等を扱う通信方式。

**具体例：** 届く順番等を確認しながらデータを送る。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## TCP/IP とは

インターネットで使われている通信の決まり（プロトコル）の集まりです。中心となる **IP**（宛先までデータを届ける）と **TCP**（確実に届ける）の名前をとっています。

## IP アドレス

ネットワーク上の機器を識別する番号です。

- **IPv4**: 32 ビット。`192.168.1.10` のように 8 ビットずつ 10 進数で書く。約 43 億個しかなく不足している
- **IPv6**: 128 ビット。`2001:db8::1` のように 16 進数で書く

| 種類 | 内容 | 例 |
|---|---|---|
| グローバル IP アドレス | インターネット上で一意 | プロバイダーから割り当てられる |
| プライベート IP アドレス | 社内や家庭内だけで使う | `10.x.x.x`、`172.16〜31.x.x`、`192.168.x.x` |
| ループバックアドレス | 自分自身 | `127.0.0.1`（`localhost`） |

### サブネットマスク

IP アドレスのうち、どこまでが **ネットワークの部分** かを表します。

```text
192.168.1.10/24
→ 先頭 24 ビット（192.168.1）がネットワーク部、残り 8 ビット（10）がホスト部
→ サブネットマスクは 255.255.255.0
→ 同じネットワークには 192.168.1.1〜192.168.1.254 の機器を置ける
```

## TCP と UDP

| | TCP | UDP |
|---|---|---|
| 接続 | 通信の前に接続を確立する（3 ウェイハンドシェイク） | 接続しない |
| 信頼性 | 届いたかを確認し、失われたら再送する。順番もそろえる | 確認しない。失われても再送しない |
| 速さ | 確認の分だけ遅い | 速い |
| 用途 | Web（HTTP）、メール、ファイル転送 | DNS の問い合わせ、動画・音声の配信、オンラインゲーム |

TCP の 3 ウェイハンドシェイク:

```text
クライアント ──SYN──────→ サーバー
クライアント ←─SYN+ACK── サーバー
クライアント ──ACK──────→ サーバー   （ここから通信開始）
```

## ポート番号

1 台のコンピューターの中で、**どのアプリケーション宛ての通信か** を区別する番号（0〜65535）です。IP アドレスが「建物の住所」なら、ポート番号は「部屋番号」です。

| ポート | 用途 |
|---|---|
| 20, 21 | FTP |
| 22 | SSH |
| 25 | SMTP（メール送信） |
| 53 | DNS |
| 80 | HTTP |
| 110 | POP3（メール受信） |
| 443 | HTTPS |
| 3306 | MySQL |
| 5432 | PostgreSQL |
| 8080 | 開発用の Web サーバーでよく使う |

- 0〜1023 は **ウェルノウンポート**（よく知られたサービス用）
- クライアント側は、通信のたびに空いている番号（エフェメラルポート）が自動で使われる

通信は「**送信元 IP:ポート → 宛先 IP:ポート**」の組で識別されます。

## 確認に使うコマンド（Windows）

```bat
rem 自分の IP アドレス
ipconfig
rem 相手に届くか
ping 192.168.1.1
rem 待ち受けているポート
netstat -ano | find "LISTEN"
```

## ポイント

- IP アドレスで機器を、ポート番号でアプリケーションを識別する
- 確実さが必要なら TCP、速さ優先なら UDP
- `localhost` は自分自身。`/24` はネットワーク部が 24 ビット

## Option：コンテナのlocalhost

ブラウザ、ホストOS、各コンテナは異なるネットワーク環境に属する場合があります。ブラウザからのlocalhostと、APIコンテナからのlocalhostは同じサーバーを指すとは限りません。
