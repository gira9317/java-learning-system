## まずはここから

パスワードを何度も試して当てようとする攻撃があります。よくある言葉や、他所で漏れた情報も使われます。利用者の工夫だけでなく、システム側で試行を制限する仕組みも必要です。

### 最初に覚える4つの言葉

#### 総当たり攻撃

候補を多数試して当てようとする攻撃。

**具体例：** 番号の組み合わせを次々に試す。

#### 辞書攻撃

よく使われる言葉等を候補として試す攻撃。

**具体例：** ありがちなパスワードを優先する。

#### レート制限

一定時間の操作回数を制限する仕組み。

**具体例：** 短時間の大量ログインを抑える。

#### 使い回し

同じパスワードを複数箇所で使うこと。

**具体例：** 別サイトでも同じ秘密を使う。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## どんな攻撃か

ログイン画面などで、パスワードを **何度も試して当てる** 攻撃です。

| 攻撃 | 内容 |
|---|---|
| ブルートフォース攻撃（総当たり攻撃） | 文字の組み合わせを片端から全部試す |
| 辞書攻撃 | よく使われるパスワード（`password`、`123456`、`qwerty` など）や単語の一覧を試す |
| リバースブルートフォース攻撃 | パスワードを 1 つに固定し、ID のほうを次々に変えて試す |
| パスワードスプレー攻撃 | よくあるパスワードを、多数のアカウントに少しずつ試す（1 アカウントあたりの失敗回数を少なくして、ロックを避ける） |
| パスワードリスト攻撃（クレデンシャルスタッフィング） | 別のサービスから漏れた ID とパスワードの組を試す。パスワードの使い回しが狙われる |

## パスワードの長さと強さ

使う文字の種類と長さで、組み合わせの数が決まります。

| 使う文字 | 種類 | 8 文字の組み合わせ |
|---|---|---|
| 数字だけ | 10 | 1 億 |
| 英小文字だけ | 26 | 約 2,000 億 |
| 英大小文字 + 数字 | 62 | 約 218 兆 |

1 文字増えるたびに、組み合わせは種類の数の倍だけ増えます。**長さが最も効く** ため、短く複雑なものより、長いもの（パスフレーズ）のほうが強くなります。

ただし、辞書に載っている単語やよくあるパターン（`Password1!` など）は、長さに関係なくすぐに当てられます。

## システム側の対策

| 対策 | 内容 |
|---|---|
| 試行回数の制限 | 一定時間に一定回数以上失敗したら、しばらく受け付けない（このシステムでは、同じ社員番号で 1 分に 5 回、同じ接続元から 20 回まで） |
| アカウントロック | 連続して失敗したら、一定時間ロックする。ただし、攻撃者が他人をロックさせる嫌がらせにも使えるため、時間で解除する |
| 多要素認証 | パスワードが当てられても、ほかの要素がなければログインできない |
| パスワードの品質チェック | 短すぎるもの、よく使われるもの、漏えいが知られているものを登録させない |
| 失敗の監視・通知 | 不審な失敗の多さを検知し、本人や管理者に知らせる |
| CAPTCHA | 人間かどうかを確かめ、自動化された攻撃を難しくする |
| ハッシュの方式 | 保存したハッシュが漏れたときに備え、計算の重い方式（Argon2、bcrypt）を使う |

## 利用者側の対策

- **長く、推測されにくいパスワード** にする
- **サービスごとに違うパスワード** にする（使い回すと、1 か所の漏えいで全部が危険になる）
- **パスワードマネージャー** を使って管理する
- 多要素認証を有効にする

## 守る側の考え方

1 つの対策で完全に防ぐのではなく、**何重にも対策を重ねる**（多層防御）ことで、攻撃にかかる時間と手間を増やし、気づいて止められるようにします。

## ポイント

- 総当たり・辞書・パスワードリスト攻撃で、パスワードは当てられる
- システム側は試行回数の制限、多要素認証、パスワードの品質チェック
- 利用者側は長いパスワードを、サービスごとに変える
- 対策を重ねて、攻撃にかかる手間を増やす

### 問1

「候補を多数試して当てようとする攻撃」に当てはまるものはどれですか。

#### 選択肢

- A. 辞書攻撃
- B. レート制限
- C. 総当たり攻撃
- D. 使い回し

#### 解答・解説

- D. 同じパスワードを複数箇所で使うこと

**辞書攻撃**：よく使われる言葉等を候補として試す攻撃。

### 問4

### 問5【応用】

パスワードの使い方として適切なのは？

#### 選択肢

- A. 共有チャットへ貼る
- B. 必ず社員番号と同じにする
- C. 全て同じものを使う
- D. サービスごとに異なるものを使う

#### 解答・解説

正解: D

他所で漏れた情報をそのまま使われないため、使い回しを避けます。

## Option：オンライン攻撃とオフライン攻撃

ログインAPIへの試行はレート制限等で抑えられますが、漏えいしたハッシュの照合は攻撃者の環境で進められます。保存方式とログイン時の対策を別々に設計します。

**参考：** [OWASP：認証](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)。

**やってみよう：** 不正試行を止めつつ、正当な利用者が復旧できる待機・通知の流れを考えてみましょう。
