## まずはここから

パソコンの中には、役割の違う部品が入っています。まずは『考える係』『作業中の置き場』『保存する場所』を分けましょう。メモリは難しい計算方法ではなく、作業途中の情報を置く部品の名前です。

### 最初に覚える4つの言葉

#### CPU

命令に従って計算や判断をする部品。

**具体例：** 入力した2+3を計算する。

#### メモリ（RAM）

作業中の情報を一時的に置く場所。

**具体例：** 開いている文書の編集中の内容を置く。

#### SSD

電源を切ってもファイルを保存しておく装置。

**具体例：** 昨日保存した写真を残しておく。

#### 入力装置

人などから情報を受け取る装置。

**具体例：** キーボードで名前を入力する。

### この講義の読み方

まず上の意味と具体例を確認し、下の4択に挑戦しましょう。詳しい仕組みやコードは「詳しい説明」、発展した内容は「Option」で後から読めます。1回で全てを暗記する必要はありません。

## ハードウェアとは

コンピューターを構成する、手で触れられる物理的な装置のことです。プログラムは最終的にハードウェアの上で動くため、各装置の役割を知っておくと、「なぜ遅いのか」「なぜメモリが足りなくなるのか」を考えられるようになります。

## コンピューターの 5 大装置

| 装置 | 役割 | 具体例 |
|---|---|---|
| 制御装置 | 命令を読み取り、ほかの装置に指示を出す | CPU |
| 演算装置 | 計算や比較を行う | CPU |
| 記憶装置 | データやプログラムを記憶する | メモリ（主記憶）、SSD・HDD（補助記憶） |
| 入力装置 | 外部からデータを受け取る | キーボード、マウス |
| 出力装置 | 結果を外部に出す | ディスプレイ、プリンター |

制御装置と演算装置をまとめたものが **CPU**（中央処理装置）です。

## 記憶装置の階層

速い記憶装置ほど高価で容量が小さいため、役割を分けて組み合わせます。

| 種類 | 速さ | 容量の目安 | 電源を切ると |
|---|---|---|---|
| レジスタ（CPU 内） | 最も速い | 数百バイト | 消える |
| キャッシュメモリ | とても速い | 数 MB | 消える |
| メインメモリ（RAM） | 速い | 数 GB〜数十 GB | 消える |
| SSD / HDD | 遅い | 数百 GB〜数 TB | 残る |

プログラムを実行するときは、SSD などに保存されたプログラムやデータを **メモリに読み込んでから** CPU が処理します。

## CPU の性能を表す言葉

- **クロック周波数**（GHz）: 1 秒間に刻む動作の回数。大きいほど速い
- **コア数**: 同時に処理できる単位の数。複数の処理を並行して進められる

## ポイント

- CPU は「考える」、メモリは「作業机」、SSD は「本棚」とたとえられる
- メモリは高速だが電源を切ると内容が消える。保存したいデータはファイルや DB に書く
- 処理が遅いときは、CPU・メモリ・ディスクのどこが詰まっているかを切り分けて考える

### 問5【応用】

書いた文書を明日も使いたいとき、することは？

#### 選択肢

- A. ファイルとして保存する
- B. マウスを動かす
- C. 画面を明るくする
- D. CPUの名前を覚える

#### 解答・解説

正解: A

作業中の情報は、保存しないと失われることがあります。保存先と作業場所は別です。

## Option：ボトルネックとアムダールの法則

処理のうち並列化できない割合が大きいほど、コア数を増やしても高速化には限界があります。実行時間の半分が直列処理なら、残りを限りなく速くしても全体の高速化は最大2倍です。

**やってみよう：** 自分のPCで、処理中のCPU・メモリ・ディスクを観察し、待ち時間がどこで発生しているか仮説を立ててみましょう。
