## ハードウェアとは

コンピューターを構成する、手で触れられる物理的な装置のことです。プログラムは最終的にハードウェアの上で動くため、各装置の役割を知っておくと、「なぜ遅いのか」「なぜメモリが足りなくなるのか」を考えられるようになります。

## コンピューターの 5 大装置

| 装置 | 役割 | 具体例 |
|---|---|---|
| 制御装置 | 命令を読み取り、ほかの装置に指示を出す | CPU |
| 演算装置 | 計算や比較を行う | CPU |
| 記憶装置 | データやプログラムを記憶する | メモリ（主記憶）、SSD・HDD（補助記憶） |
| 入力装置 | 外部からデータを受け取る | キーボード、マウス |
| 出力装置 | 結果を外部に出す | ディスプレイ、プリンター |

制御装置と演算装置をまとめたものが **CPU**（中央処理装置）です。

## 記憶装置の階層

速い記憶装置ほど高価で容量が小さいため、役割を分けて組み合わせます。

| 種類 | 速さ | 容量の目安 | 電源を切ると |
|---|---|---|---|
| レジスタ（CPU 内） | 最も速い | 数百バイト | 消える |
| キャッシュメモリ | とても速い | 数 MB | 消える |
| メインメモリ（RAM） | 速い | 数 GB〜数十 GB | 消える |
| SSD / HDD | 遅い | 数百 GB〜数 TB | 残る |

プログラムを実行するときは、SSD などに保存されたプログラムやデータを **メモリに読み込んでから** CPU が処理します。

## CPU の性能を表す言葉

- **クロック周波数**（GHz）: 1 秒間に刻む動作の回数。大きいほど速い
- **コア数**: 同時に処理できる単位の数。複数の処理を並行して進められる

## ポイント

- CPU は「考える」、メモリは「作業机」、SSD は「本棚」とたとえられる
- メモリは高速だが電源を切ると内容が消える。保存したいデータはファイルや DB に書く
- 処理が遅いときは、CPU・メモリ・ディスクのどこが詰まっているかを切り分けて考える

> **確認しよう**
>
> - 5 大装置のうち、CPU が担っているのはどれとどれでしょうか。
> - プログラムを保存しておくのはどの装置で、実行するときはどの装置に読み込まれるでしょうか。
