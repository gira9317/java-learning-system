## エンコードとデコード

- **エンコード（符号化）**: データを、決まった規則で別の形式に変換すること
- **デコード（復号化）**: エンコードされたデータを、元の形に戻すこと

暗号化と違い、エンコードは **秘密を守るためのものではありません**。規則を知っていれば誰でも元に戻せます。目的は、「その場所で扱える形にする」ことです。

## 代表的なエンコード

| 方式 | 目的 | 例 |
|---|---|---|
| 文字コード（UTF-8 など） | 文字をバイト列にする | 「あ」→ `E3 81 82` |
| URL エンコード（パーセントエンコード） | URL に使えない文字を表す | 「東京」→ `%E6%9D%B1%E4%BA%AC` |
| Base64 | バイナリを英数字だけの文字列にする | 画像をメールや JSON に載せる |
| HTML エスケープ | HTML として解釈させない | `<` → `&lt;` |

## URL エンコード

URL には使える文字が決まっているため、日本語や空白、`&` `=` などの記号は `%` と 16 進数で表します。

```java
import java.net.URLDecoder;
import java.net.URLEncoder;
import java.nio.charset.StandardCharsets;

String encoded = URLEncoder.encode("東京 駅", StandardCharsets.UTF_8);
System.out.println(encoded); // %E6%9D%B1%E4%BA%AC+%E9%A7%85（空白は +）

String decoded = URLDecoder.decode(encoded, StandardCharsets.UTF_8);
System.out.println(decoded); // 東京 駅
```

## Base64

3 バイト（24 ビット）を 6 ビットずつ 4 つに分け、それぞれを 64 種類の文字（A-Z, a-z, 0-9, +, /）に置き換えます。データ量は約 **4/3 倍** に増えます。

```java
import java.util.Base64;

byte[] data = "Hello".getBytes(StandardCharsets.UTF_8);
String b64 = Base64.getEncoder().encodeToString(data);
System.out.println(b64); // SGVsbG8=

byte[] back = Base64.getDecoder().decode(b64);
System.out.println(new String(back, StandardCharsets.UTF_8)); // Hello
```

末尾の `=` は、長さを 4 の倍数にそろえるための詰め物（パディング）です。

> Base64 は暗号ではありません。パスワードなどを Base64 にしても、誰でも元に戻せます。

## HTML エスケープ

利用者が入力した文字をそのまま HTML に出すと、`<script>` などがタグとして動いてしまいます。表示する前に、特別な意味を持つ文字を置き換えます。

| 文字 | 置き換え |
|---|---|
| `<` | `&lt;` |
| `>` | `&gt;` |
| `&` | `&amp;` |
| `"` | `&quot;` |
| `'` | `&#39;` |

これは第 5 章のセキュリティ（JavaScript インジェクション対策）でも重要になります。

## ポイント

- エンコードは「形式を変えること」で、秘密は守らない
- エンコードした側とデコードする側で、同じ方式・同じ文字コードを使う
- 用途によって使い分ける（URL、Base64、HTML エスケープ）

> **確認しよう**
>
> - 「Base64 にしたので安全」と言われたら、どう答えますか。
> - 検索語に「C&A」を入れた URL を作るとき、エンコードしないと何が起きるでしょうか。
