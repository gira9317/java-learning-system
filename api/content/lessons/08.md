---
title: メソッド
---

## このレッスンの目標

- まとまった処理をメソッドとして定義できる
- 引数と戻り値の役割を説明できる
- 計算と表示を分けて考えられる

## 処理に名前を付ける

```java
public class Main {
    static int add(int left, int right) {
        return left + right;
    }

    public static void main(String[] args) {
        int result = add(3, 5);
        System.out.println(result); // 8
    }
}
```

`add`がメソッド名、`left`と`right`が引数です。呼び出すときに渡した`3`と`5`を使って計算します。
メソッド名の前の`int`は戻り値の型で、`return`が計算結果を呼び出し元へ返します。

## 戻り値がないメソッド

```java
static void greet(String name) {
    System.out.println(name + "さん、こんにちは");
}
```

値を返さない場合は、戻り値の型を`void`にします。
表示することと値を返すことは別の操作です。`println`で表示しても、その値を呼び出し元の計算には使えません。

## 変数の使える範囲

メソッド内で宣言したローカル変数は、別のメソッドから直接使えません。
必要な値を引数で渡し、結果を戻り値で受け取りましょう。

> この例では、`main`から呼ぶ補助メソッドも`static`にしています。インスタンスのメソッドは次のレッスンで扱います。

## 確認ポイント

- 引数の数・順番・型が定義と一致していますか
- 戻り値があるメソッドは、必要なすべての経路で値を返していますか
- 1つのメソッドに複数の役割を詰め込みすぎていませんか
