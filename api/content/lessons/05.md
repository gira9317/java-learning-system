## このレッスンの目標

- 初期化・継続条件・更新の役割を説明できる
- 決まった回数の処理を`for`文で書ける
- 繰り返し回数のずれを確認できる

## for文の基本形

```java
for (int i = 0; i < 3; i++) {
    System.out.println(i);
}
```

出力は順番に`0`、`1`、`2`です。`3`は表示されません。

1. `int i = 0`で変数を初期化する（最初の1回だけ）
2. `i < 3`が成り立つか調べる
3. 成り立つ場合、ブロック内を実行する
4. `i++`で値を1増やし、条件の確認に戻る

条件が`false`になると、繰り返しを終えて次の処理へ進みます。

## 合計を求める

```java
int total = 0;
for (int number = 1; number <= 4; number++) {
    total += number;
}
System.out.println(total); // 10
```

`total += number`は`total = total + number`と同じ意味です。
合計を保存する変数は繰り返しの外で初期化します。内側で毎回`0`に戻すと、値を積み重ねられません。

## フロー図で考える

「初期化 → 条件判定 → 処理 → 更新 → 条件判定」の順に並べます。
条件がFalseになった経路は、繰り返しの外へつなぎます。

## 確認ポイント

- 最初と最後に使う値を、実行前に予測できますか
- `<`と`<=`のどちらが適切ですか
- 0回・1回だけ繰り返す場合でも正しく動きますか
