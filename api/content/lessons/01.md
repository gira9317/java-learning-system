## このレッスンの目標

- Javaプログラムの基本構造を説明できる
- `main`メソッドから処理が始まることを理解する
- 文字列を標準出力に表示できる

## 最初のプログラム

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

このプログラムを実行すると、画面に`Hello, Java!`と表示されます。
`Main`はクラスの名前です。上の例をファイルに保存する場合、ファイル名は`Main.java`にします。

`public static void main(String[] args)`は、プログラムの実行開始位置です。
最初はこの形を使い、波かっこ`{ }`の中に処理を書きましょう。

## 文字を表示する

`System.out.println`は、指定した値を表示して最後に改行します。
文字列は半角のダブルクォーテーション`"`で囲み、文の最後にはセミコロン`;`を付けます。

```java
System.out.println("おはようございます");
System.out.println("Javaの学習を始めます");
```

処理は上から順に実行されるので、表示も同じ順番になります。
`System.out.print`を使うと、表示した後に改行しません。

## コメント

```java
// この行は説明なので実行されません
System.out.println("研修中です");
```

## フロー図で考える

「開始 → 文字を表示する → 終了」の順に並べます。
コードを書く前に、表示したい内容と順番を決めておきましょう。

## 確認ポイント

- クラス名とファイル名は一致していますか
- 大文字・小文字、かっこ、セミコロンは正しいですか
- 指定された出力に、余分な説明文や空白が入っていませんか
