title: 変数に値を入れてみよう
---

## 値に名前を付けよう

変数は、値を名前で覚えておく仕組みです。最初は「名前の付いた箱」と考えましょう。

```java
int count = 3;
System.out.println(count);
```

`int`は整数を扱う種類、`count`は自分で付けた名前、`3`は覚えておく値です。表示するときは`count`を引用符で囲みません。`"count"`にすると、中の値ではなくcountという文字が出ます。

## 文字を覚える変数

```java
String name = "太郎";
System.out.println(name);
```

`String`は文字列を扱う種類です。整数と文字列で種類を分けます。種類のことを**型**と呼びます。

## 後から値を変える

```java
int count = 2;
count = count + 1;
System.out.println(count);
```

表示は3です。`=`は「右の結果を左へ入れる」という意味で、算数の等号とは違います。上から順番に、2を入れる→今の2に1を足す→3を表示する、と追いましょう。

最初に変数を作るときはintを書きます。同じ変数の値を更新するだけなら、intはもう一度書きません。
