title: 自由制作
---

## このレッスンの目標

- 正解が1つではない課題で、何を作るかを自分で決められる
- 作る前に、使い方とクラスの分け方を簡単に設計できる
- 利用者が実際に入力しながら使えるプログラムを作れる
- 自分の設計の意図を、メモとコードで人に伝えられる

## このレッスンの進め方

これまでの演習は、決まった入力に決まった出力を返せば合格でした。このレッスンには自動採点の正解がありません。**必須**の機能が動けば提出でき、研修担当者がレビューで評価します。**発展**は、時間があれば取り組んでください。

1. `Main.java` 先頭のメモに「作るもの・使い方・クラスの分け方」を書く
2. 必須の機能を1つずつ作り、「対話」タブで動かして確かめる
3. おかしな入力（文字・範囲外・空の入力）を試し、止まらないようにする
4. メモの「工夫したところ・できなかったこと」を書いて提出する

## 対話で動かす

演習画面のコンソールの「対話」タブで「対話で実行」を押すと、プログラムが起動して入力待ちになります。下の欄に入力して Enter を押すと、プログラムに1行届き、応答が表示されます。プログラムが終わるか「止める」を押すまで、何度でもやり取りできます。

```java
Scanner sc = new Scanner(System.in);
System.out.println("コマンド: buy 番号 / quit");
while (sc.hasNextLine()) {          // 入力を待つ
    String line = sc.nextLine();
    if (line.equals("quit")) break;
    // ...
}
```

- 入力を待つ前に、何を入力すればよいかを表示しましょう
- コードを変えたら「最初から実行し直す」で反映されます
- しばらく入力がないと、自動で止まります

## 止まらないプログラムにする

利用者は、思いもよらない入力をします。

```java
try {
    int amount = Integer.parseInt(cmd[1]);
} catch (NumberFormatException | ArrayIndexOutOfBoundsException e) {
    System.out.println("金額は数字で入力してください（例: insert 100）");
}
```

例外で止まる代わりに、どう直せばよいかを伝えるのが親切なプログラムです。

## 設計のヒント

- **名詞を探す**：自動販売機なら「商品」「お金」「自動販売機」。名詞はクラスの候補です
- **動詞を探す**：「入れる」「買う」「返す」。動詞はメソッドの候補です
- **`Main` は薄く**：入力と表示だけにして、ルールは別のクラスに書きます（「小さな業務システム」と同じ）
- **小さく動かす**：一度に全部書かず、1つの機能ができたら動かして確かめます

## 確認ポイント

- 必須の機能がすべて動きますか
- 先頭のメモを読めば、使い方と構成が分かりますか
- おかしな入力をしても、プログラムが止まりませんか
- `Main` に全部を書かず、役割ごとにクラスを分けていますか
