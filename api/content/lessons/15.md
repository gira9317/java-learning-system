title: 入力を受け取ってみよう
---

## コードを変えずに、データを変えてみる

今まではコードへ名前や数を直接書きました。外からデータを渡せると、同じコードで違う名前や数字を扱えます。これを**入力**と考えましょう。

## この演習での入力欄

「実行」時の**コマンドライン引数**という欄を使います。太郎と入力して渡すと、`args[0]`でその文字を受け取れます。

```java
System.out.println(args[0]);
```

表示は太郎です。入力を花子へ変えてもう一度実行すると、花子と出ます。

2つ渡すときは、`赤 青`のように半角空白で区切ります。最初は`args[0]`、2つ目は`args[1]`です。0から数える点は見慣れないかもしれませんが、まずこの2つから試しましょう。

## 数字も最初は文字として届く

```java
int number = Integer.parseInt(args[0]);
System.out.println(number + 1);
```

入力が3なら、文字を整数3へ変えて1を足し、4を表示します。`Integer.parseInt`は「整数へ変換する道具」として使いましょう。ここでは必要な行を最初から用意します。

引数が必要な問題では、入力を空にしないようにします。文字を数値へ変える問題では、まず指定された整数を入力してください。不正な入力の扱いは後の例外処理で学びます。
