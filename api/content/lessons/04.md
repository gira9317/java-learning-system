## このレッスンの目標

- 1つの値に応じた分岐を`switch`で書ける
- `case`、`break`、`default`の役割を理解する
- 範囲の判定と値の一致を使い分けられる

## 値に応じて分岐する

```java
int menu = 2;
switch (menu) {
    case 1:
        System.out.println("登録");
        break;
    case 2:
        System.out.println("検索");
        break;
    default:
        System.out.println("該当するメニューがありません");
        break;
}
```

`switch`の値と一致する`case`から処理を始めます。どれにも一致しなければ`default`へ進みます。
この例の出力は`検索`です。

## breakの役割

コロン`:`で書く形式では、`break`がないと次の`case`の処理にも進みます。これをフォールスルーと呼びます。
意図しない表示が増えていないか確認しましょう。

```java
int day = 6;
switch (day) {
    case 6:
    case 7:
        System.out.println("休日");
        break;
    default:
        System.out.println("平日");
        break;
}
```

上のように、複数の値を同じ処理にまとめる使い方もあります。

## if文との使い分け

`switch`は「1、2、3のどれか」のような値の一致に向いています。
「60以上」「9以上かつ18未満」といった範囲の判定には`if`文を使うと読みやすくなります。

## 確認ポイント

- 必要な`break`が抜けていませんか
- 想定外の値を受け取った場合の処理がありますか
- すべての選択肢で出力を確認しましたか
