## 記号を1つずつ試そう

| したい計算 | Javaの記号 | 例 | 結果 |
| --- | --- | --- | --- |
| 足す | `+` | `4 + 2` | 6 |
| 引く | `-` | `7 - 3` | 4 |
| 掛ける | `*` | `3 * 4` | 12 |
| 割る | `/` | `7 / 2` | 3（整数同士） |
| 余りを求める | `%` | `7 % 2` | 1 |

掛け算は×、割り算は÷ではなく、半角の`*`と`/`を使います。

## 変数を使って計算する

```java
int a = 4;
int b = 2;
System.out.println(a + b);
```

aに4、bに2が入っているので6を表示します。まずは表示の行の記号だけを変えて、結果を比べましょう。

## 割り算と余りを分けて考える

7個のお菓子を2人へ同じ数ずつ分けると、1人3個で1個余ります。整数同士の`7 / 2`は3、`7 % 2`は1です。

小数の計算もできますが、ここでは整数だけを使います。0で割ることはできないので、割る数が0にならないようにします。
