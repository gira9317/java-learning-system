---
title: 数字と文字を区別しよう
---

## 見た目が似ていても、意味が違う

```java
System.out.println(2 + 3);
System.out.println("2 + 3");
```

1行目は計算をして`5`を表示します。2行目は文字として`2 + 3`をそのまま表示します。ダブルクォーテーションで囲んだ部分は、文章として扱われます。

## 文字と数値を一緒に表示する

```java
System.out.println("人数: " + 3);
```

表示は`人数: 3`です。文字列の後の`+`は、表示内容をつなぐ役目にも使えます。

```java
System.out.println("合計: " + (2 + 3));
```

表示は`合計: 5`です。かっこの中の計算を先に行います。内側のかっこを外すと、左から文字をつないで`合計: 23`になります。

## 練習の進め方

最初は「実行する前に何が表示されるか予想する→実行して比べる」でかまいません。日本語の文字は自由に変えられますが、引用符やかっこは半角の記号を使います。
