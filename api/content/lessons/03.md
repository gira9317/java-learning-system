## このレッスンの目標

- 条件式の結果が`true`か`false`になることを理解する
- `if`と`else`で処理を分けられる
- 境界値を使って条件の間違いを確かめられる

## if文の基本形

プログラムは上から順に実行されます。条件によって処理を変えたいときは、`if`文を使います。

```java
int temperature = 28;
if (temperature >= 25) {
    System.out.println("暑いです");
} else {
    System.out.println("過ごしやすいです");
}
```

条件式が`true`なら最初のブロック、`false`なら`else`のブロックだけを実行します。

## 比較演算子

| 演算子 | 意味 | 例 |
| --- | --- | --- |
| `==` | 等しい | `a == b` |
| `!=` | 等しくない | `a != b` |
| `>` | より大きい | `age > 18` |
| `>=` | 以上 | `age >= 18` |
| `<` | より小さい | `age < 18` |
| `<=` | 以下 | `age <= 18` |

`>`と`>=`では、指定した値ちょうどのときの結果が変わります。

## 複数の条件を組み合わせる

`&&`は「両方が成り立つ」、`||`は「少なくとも一方が成り立つ」を表します。

```java
int hour = 12;
if (hour >= 9 && hour < 18) {
    System.out.println("営業時間内です");
}
```

> 文字列の内容を比較するときは、原則として`==`ではなく`equals`を使います。例：`"Java".equals(language)`。

## コマンドライン引数を数値にする

この演習では、標準入力ではなくコマンドライン引数から点数を受け取ります。

```java
int score = Integer.parseInt(args[0]);
```

`args[0]`は最初の引数です。文字列として届くため、`Integer.parseInt`で整数に変換します。
この行は、引数が1つ以上あり、その内容を整数に変換できることを前提としています。

## フロー図と境界値

条件分岐はひし形で表し、分岐先にTrue・Falseを付けます。両方の経路が終了につながることを確かめましょう。

演習の条件は「60点以上なら合格」です。`80`のような通常の値に加え、境目の`60`と直前の`59`で確認してください。
公開されているテスト以外にも、条件を満たす値を考えてみましょう。

## 確認ポイント

- 「以上」と「より大きい」を取り違えていませんか
- 合格と不合格の両方を確認しましたか
- 出力する文字列は、問題文の指定と一致していますか
