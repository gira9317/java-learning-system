---
title: 変数とデータ型
---

## このレッスンの目標

- 値の種類に合わせて変数の型を選べる
- 変数の宣言・代入・更新ができる
- 整数同士の割り算と文字列の連結を理解する

## 変数に値を保存する

変数は、値に名前を付けて保存する仕組みです。宣言は`型 名前 = 初期値;`の形で書きます。

```java
int quantity = 3;
double price = 120.5;
String productName = "ノート";
boolean inStock = true;
```

| 型 | 保存する値 | 例 |
| --- | --- | --- |
| `int` | 整数 | `3`、`-10` |
| `double` | 小数を含む数値 | `120.5` |
| `String` | 文字列 | `"ノート"` |
| `boolean` | 真偽値 | `true`、`false` |

## 計算と代入

```java
int count = 2;
count = count + 3;
System.out.println(count); // 5
```

`=`は「等しいか調べる」記号ではなく、右側の計算結果を左側の変数へ代入する記号です。
計算には`+`、`-`、`*`、`/`、余りを求める`%`を使えます。

```java
System.out.println(7 / 2);   // 3：整数同士では小数部分が切り捨てられる
System.out.println(7 / 2.0); // 3.5
System.out.println(7 % 2);   // 1
```

## 文字列と数値を組み合わせる

```java
int apples = 2;
int oranges = 3;
System.out.println("合計: " + (apples + oranges)); // 合計: 5
```

`+`は文字列の連結にも使います。かっこを外して`"合計: " + apples + oranges`とすると、左から連結されて`合計: 23`になります。

## 確認ポイント

- 小数が必要な計算を整数同士で行っていませんか
- 変数に代入する前に使っていませんか
- 値を更新するときに、同じ変数をもう一度宣言していませんか
