title: コレクション（List と Map）
---

## このレッスンの目標

- 数が決まっていないデータを `List` で扱える
- 名前と値の対応を `Map` で扱える
- 自分で作ったクラスを `List` に入れ、並べ替えや集計ができる
- 目的に合ったコレクションの種類を選べる

## List：順番に並べて持つ

配列は作るときに長さを決めますが、`List` はあとから何個でも足せます。

```java
import java.util.ArrayList;
import java.util.List;

List<String> names = new ArrayList<>();
names.add("佐藤");
names.add("鈴木");
System.out.println(names.size());   // 2
System.out.println(names.get(0));   // 佐藤
for (String name : names) {
    System.out.println(name);
}
```

`<String>` の部分で、何を入れるかを決めます。`int` のような基本の型は入れられないので、`List<Integer>` のように書きます。

## 自分のクラスを入れる

1件分のデータをまとめたクラス（または `record`）を作って `List` に入れると、関係のある値をばらばらにせずに扱えます。

```java
record Item(String name, int price) {}

List<Item> cart = new ArrayList<>();
cart.add(new Item("りんご", 120));
cart.add(new Item("みかん", 80));

int total = 0;
for (Item item : cart) total += item.price();
```

`record` は、値を持つだけのクラスを短く書く方法です。`item.price()` のように、項目名のメソッドで値を取り出せます。

## 並べ替える

`sort` に「どちらを前にするか」の比べ方を渡します。

```java
cart.sort((a, b) -> a.price() - b.price());                 // 安い順
cart.sort(Comparator.comparing(Item::price).reversed());     // 高い順
cart.sort(Comparator.comparing(Item::price).thenComparing(Item::name)); // 値段、同じなら名前
```

`List` の `sort` は**安定**です。比べた結果が同じものは、元の順番のまま残ります。

## Map：名前から値を引く

`Map` は「キー → 値」の対応表です。在庫数や回数を数えるときに便利です。

```java
import java.util.HashMap;
import java.util.Map;

Map<String, Integer> stock = new HashMap<>();
stock.put("りんご", 10);
stock.put("りんご", stock.get("りんご") - 3);    // 7
int lemon = stock.getOrDefault("レモン", 0);      // ないときは 0
stock.merge("みかん", 5, Integer::sum);          // なければ 5、あれば足す

for (Map.Entry<String, Integer> e : stock.entrySet()) {
    System.out.println(e.getKey() + ": " + e.getValue());
}
```

## 種類の選び方

| 種類 | 特徴 | 使いどころ |
|---|---|---|
| `ArrayList` | 入れた順、番号で取り出せる | ふつうの一覧 |
| `HashMap` | キーで速く引ける。順番は決まらない | 検索・集計（表示順を問わない） |
| `LinkedHashMap` | キーで引けて、入れた順を保つ | 入れた順に表示したい集計 |
| `TreeMap` | キーの順（あいうえお順・数の順）に並ぶ | 並べて表示したい集計 |

`HashMap` の表示順はたまたま決まるので、「入った順に表示する」という仕様なら `LinkedHashMap` を選びます。

## 確認ポイント

- 個数が決まっていないデータを、配列ではなく `List` で持っていますか
- 関係のある値（名前と値段など）を、クラスや `record` にまとめていますか
- `Map` の種類を、表示の順番の仕様に合わせて選んでいますか
- 同じ値のときの並び順まで、仕様どおりになっていますか
