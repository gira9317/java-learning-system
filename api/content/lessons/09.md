---
title: クラスとオブジェクト
---

## このレッスンの目標

- クラスとインスタンスの関係を説明できる
- フィールドとメソッドを使える
- コンストラクタで初期状態を設定できる

## データと処理をまとめる

クラスは、持たせるデータと処理を定義する設計図です。そのクラスから作った実体をインスタンス（オブジェクト）と呼びます。

```java
class Counter {
    private int count;

    Counter(int initialCount) {
        count = initialCount;
    }

    void increment() {
        count++;
    }

    int getCount() {
        return count;
    }
}

public class Main {
    public static void main(String[] args) {
        Counter counter = new Counter(0);
        counter.increment();
        System.out.println(counter.getCount()); // 1
    }
}
```

`count`はインスタンスが持つフィールドです。`increment`と`getCount`は、そのインスタンスに対する操作です。
上のコードは1つの`Main.java`に保存できます。

## コンストラクタ

`new Counter(0)`でインスタンスを作るとき、`Counter(int initialCount)`が実行されます。
これをコンストラクタと呼びます。クラスと同じ名前を使い、戻り値の型は書きません。

## インスタンスごとの状態

```java
Counter first = new Counter(0);
Counter second = new Counter(10);
first.increment();
System.out.println(first.getCount());  // 1
System.out.println(second.getCount()); // 10
```

別々に作ったインスタンスは、それぞれの`count`を持ちます。
ただし`Counter second = first;`のような代入では、新しいインスタンスは作られず、同じものを参照します。

## 確認ポイント

- `new`でインスタンスを作ってから使っていますか
- フィールドを`private`にし、必要な操作をメソッドで提供していますか
- 別のインスタンスと、同じインスタンスへの参照を区別できますか
