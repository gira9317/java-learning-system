title: 繰り返し — while文
---

## このレッスンの目標

- 条件が成り立つ間の処理を`while`文で書ける
- 繰り返しが終了する理由を説明できる
- `while`と`do-while`の違いを理解する

## while文の基本形

```java
int remaining = 3;
while (remaining > 0) {
    System.out.println(remaining);
    remaining--;
}
System.out.println("終了");
```

`3`、`2`、`1`、`終了`の順に表示されます。
ブロックを実行する前に条件を調べるため、最初から条件が成り立たなければ処理は0回です。

## 終了条件を考える

上の例で`remaining--`を書き忘れると、値が変わらず、繰り返しが終わりません。
繰り返しを作るときは、何が変化し、どの状態で終了するかを先に決めましょう。

```java
int value = 100;
int count = 0;
while (value > 1) {
    value /= 2;
    count++;
}
System.out.println(count); // 6
```

## 必ず1回は実行する場合

```java
int count = 0;
do {
    System.out.println("実行しました");
    count++;
} while (count < 0);
```

`do-while`は処理の後に条件を調べるので、この例でも1回表示されます。
最後のセミコロンを忘れないようにしましょう。

## 確認ポイント

- 条件の判定に使う値は、繰り返しの中で変化しますか
- 最初から条件がFalseのとき、何が出力されますか
- 終了しないループになっていませんか
