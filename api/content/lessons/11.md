title: はじめての実行と文字の表示
---

## プログラムって何？

コンピューターへの「やってほしいことの手順」です。文字で書いた手順を**コード**、その手順を動かすことを**実行**と呼びます。ここではコードを全部覚える必要はありません。

## まずは、そのまま動かそう

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("こんにちは");
    }
}
```

1. 「演習に進む」を押します。
2. 「実行」を押します。
3. 下の出力欄に「こんにちは」が出ることを確かめます。

`System.out.println`は、かっこの中の内容を表示する命令です。`"こんにちは"`のように、表示したい文字を半角のダブルクォーテーションで囲みます。

## 変える場所は、まず1か所だけ

「こんにちは」を「おはよう」に変えると、表示も変わります。外側の`public class Main`や`main`は、今はプログラムを動かすための枠だと思って、そのまま残しましょう。

表示する文は上から順に動きます。`println`を2行書けば、表示も2行になります。文末の`;`と、開いたかっこの閉じ忘れに注意します。

## エラーが出ても大丈夫

エラーは「このままでは動かせない」というお知らせです。最後に変えた行を見て、引用符・かっこ・セミコロンを確認しましょう。まず1か所変えて実行する、を繰り返せば十分です。

入門編はコードだけで取り組めます。フロー図は通常レッスンへ進んでから扱います。
