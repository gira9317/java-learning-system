title: 配列
---

## このレッスンの目標

- 同じ型の複数の値を配列で扱える
- 添字が0から始まることを理解する
- 配列と繰り返しを組み合わせられる

## 配列を作る

```java
int[] scores = {70, 85, 90};
System.out.println(scores[0]); // 70
System.out.println(scores.length); // 3
scores[1] = 88;
```

`scores[0]`の`0`を添字（インデックス）と呼びます。
要素が3つなら、使える添字は`0`、`1`、`2`です。`scores[3]`にアクセスすると例外になります。

## 繰り返しで処理する

```java
int[] prices = {100, 250, 80};
int total = 0;
for (int i = 0; i < prices.length; i++) {
    total += prices[i];
}
System.out.println(total); // 430
```

要素数を直接書くより`length`を使うと、配列の大きさを変えても同じループで処理できます。

## 拡張for文

添字を使う必要がなく、各要素を順番に読むだけなら、拡張for文を使えます。

```java
String[] names = {"佐藤", "鈴木"};
for (String name : names) {
    System.out.println(name);
}
```

## 確認ポイント

- 添字の最大値を`length - 1`にしていますか
- 空の配列で、存在しない先頭要素を読んでいませんか
- 平均を求める場合、要素数0と整数同士の割り算に配慮していますか
